# Q-14：燃焼の期間と燃える割合の式

## 決めること

Wiebe 関数の燃焼の期間と，燃える割合（部分燃焼，失火）を，筒内の状態（既燃ガスの割合，当量比，未燃部の温度，密度，回転数）からどう決めるか．

## 判断の材料

サイクル変動を決定論的な結合から出す（R-14）には，この依存が要る．候補は，層流燃焼速度の相関式（圧力，未燃部の温度，当量比，既燃ガスの割合の関数）に燃焼の期間を連動させる形（`ice_2026` の SPEC-07 の考え方）と，火炎が排気弁の開く前に届かない分を燃え残りとする形．経験定数になるので，値と決め方を仕様書に書く（G-03 の C-7）．

## 選択肢

仕様で式を決める．

## 決定

式の形は決めた（2026-11-28．利用者：「はい．ただ要検討かな．進めるしかない」）：着火遅れと燃焼の期間は，点火の時点の層流燃焼速度（E-X07．Metghalchi と Keck）から，無次元の量の 1/3 乗で決める（E-X02，E-X08，E-X09）．燃える割合は置かずに，燃焼が終わるまでに燃えた割合とする（E-X03，E-X06）．定数は利用者が変えられる設定．要検討として残す点は D-11．
