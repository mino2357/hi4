# Q-06：排気弁を通る既燃ガスの組成の移し方

## 決めること

筒内の化学平衡の既燃ガスを，排気弁を通るときに凍結の組成へ移すときの，エネルギーの扱い．

## 判断の材料

生成 enthalpy を含む絶対値で全 enthalpy を保てば，温度が決まる．

## 選択肢

仕様で式を決める．

## 決定

不要になった：筒内も管も同じ組成の決め方（CO と NO の反応速度の式と，拘束した平衡．D-24）にしたので，排気弁で組成を移すことが無い（Q-11，Q-12 の決定による）．
