# Q-07：リッチの既燃ガスの，管の中での凍結の組成

## 決めること

$\phi > 1$ の既燃ガス（CO，H₂ を含む）の，管の中での組成の表の作り方．

## 判断の材料

P-36 を採らず，当量比の設定の上限を $1$ にしないかぎり要る．

## 選択肢

仕様で決める．

## 決定

不要になった：リッチの既燃ガスの管の中の組成は，CO の反応速度の式と拘束した平衡（D-24）から決まる（Q-11，Q-12 の決定による）．
