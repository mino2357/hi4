# Q-13：拘束した平衡の計算の仕方

## 決めること

拘束した平衡（D-24）を，管のすべてのセルと容積，筒内のゾーンで，毎ステップどう求めるか．

## 判断の材料

変数は温度，圧力，元素の量（当量比に当たる量），CO と NO の量．表にすると次元が多い．温度が低い所（解離が無視できる）では，残りの種は CO₂，H₂O，N₂，O₂，H₂ だけになり，元素の収支だけから代数的に決まる．計算の量は，測ってから決める．

## 選択肢

(a) 低温では元素の収支から代数的に求め，高温だけ平衡を解く（切り替えの温度で値が連続になるようにする）．

(b) 表を作って補間する．

(c) その場で毎回解く．
