# Q-16：実装の言語

## 決めること

計算の核を何の言語で書くか．

## 判断の材料

- 量の単位や種類を型で表せる言語なら，単位の食い違いや，定義していない量を使う誤りを，コンパイルの時点で検出できる．
- `ice_2026` は JavaScript だけで書いた単一の HTML（G-03 の C-1）．
- 開発の環境に Rust（cargo 1.97.0）があることを確かめた．WebAssembly の target はまだ入っていない．

## 選択肢

(a) JavaScript（`ice_2026` と同じ）．

(b) Rust で書き，WebAssembly にして HTML に入れる．

## 決定

(b)．「実装言語も型で分かるような言語を使う．Rust が良いだろう．そこから HTML に落とせばよい」（利用者）．成果物が単一の HTML であること（G-03 の C-1）は変えない．
