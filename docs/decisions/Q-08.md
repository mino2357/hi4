# Q-08：過給機の map の式と寸法

## 決めること

コンプレッサとタービンの map の式の選択と，対象の機関に合わせた寸法．

## 判断の材料

D-15 と D-22 の出典にある形から選ぶ．値と決め方を仕様書に書く（G-03 の C-7）．

## 選択肢

仕様で決める．

## 決定

式の形は決めた（2026-11-28．利用者の承認は R-25，R-26 で確かめる）：コンプレッサは，流量係数と揚程係数の関係を Moore と Greitzer の 3 次式（E-C11），効率を流量係数の 2 次式（E-C04）．タービンは，流量をスクロールの出口の絞りと翼車の絞りの直列（E-T07，E-T10），効率を速度比の 2 次式（E-T06）．翼車の径，面積，曲線の形の定数の値は，まだ決めていない（対象の機関に合わせて，仕様で決める）．
