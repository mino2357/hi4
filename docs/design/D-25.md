# D-25：twin-scroll の式（2 つのスクロールが翼車の直前で合流する形）

乗用車の twin-scroll（twin-entry）は，仕切り壁で軸方向に分けた 2 つのスクロールが，翼車の直前で合流する．これを，2 つの絞りが共通の空間に入り，そこから翼車を通る形で表す．

## 記号

| 記号 | 意味 |
| :--- | :--- |
| $p_{0i}$，$T_{0i}$，$H_i$ | スクロール $i$（$i = 1, 2$）の出口のよどみ圧，よどみ温度，比全 enthalpy |
| $p_m$，$T_m$，$H_m$ | 共通の空間の圧力，温度，比全 enthalpy |
| $p_4$ | タービンの出口の静圧 |
| $A_n$，$A_r$ | スクロール 1 本の出口の絞りの有効な面積，翼車の有効な面積 |
| $\dot m_i$，$\dot m_r$ | スクロール $i$ から共通の空間へ入る質量流量（逆流は負），翼車を通る質量流量 |
| $\Psi(r)$ | 圧縮性のオリフィスの流量の関数（D-08） |
| $\Delta h_{s,i}$ | $(p_{0i}, T_{0i})$ から $p_4$ までの等エントロピーの enthalpy の落差 |

## 流量を決める式

絞り（上流のよどみ状態で流量が決まる）：

```math
\dot m_i =
\begin{cases}
\;\;A_n\,\dfrac{p_{0i}}{\sqrt{R\,T_{0i}}}\;\Psi\!\left(\dfrac{p_m}{p_{0i}}\right) & p_{0i} \ge p_m \quad (\text{順流}) \\[3ex]
-A_n\,\dfrac{p_m}{\sqrt{R\,T_m}}\;\Psi\!\left(\dfrac{p_{0i}}{p_m}\right) & p_{0i} < p_m \quad (\text{逆流})
\end{cases}
```

翼車：

```math
\dot m_r = A_r\,\frac{p_m}{\sqrt{R\,T_m}}\;\Psi\!\left(\frac{p_4}{p_m}\right)
```

共通の空間は気体をためない（体積が小さい）とする：

```math
\dot m_1(p_m) + \dot m_2(p_m) = \dot m_r(p_m)
```

未知数は $p_m$ の 1 つ．左辺は $p_m$ について単調に減り，右辺は単調に増えるので，解は 1 つに決まる．片方のスクロールに圧力の山が来て $p_m$ がもう片方のよどみ圧を超えると，逆流の枝で，排気の一部がもう片方のスクロールへ流れ込む（干渉）．干渉の強さを決める係数は置かず，$A_n$ と $A_r$ の比から決まる．

## エネルギーと成分

入ってくる流れの集合を $\mathcal I = \{i : \dot m_i > 0\}$ と書く．共通の空間の全 enthalpy と成分は，入ってくる流れの混合で決まる．

```math
H_m = \frac{\sum_{i \in \mathcal I} \dot m_i\,H_i}{\sum_{i \in \mathcal I} \dot m_i}, \qquad
Y_{k,m} = \frac{\sum_{i \in \mathcal I} \dot m_i\,Y_{k,i}}{\sum_{i \in \mathcal I} \dot m_i}
```

逆流するスクロールへは，$H_m$，$Y_{k,m}$ の気体が入る．出口の容積へは，全 enthalpy $\dot m_r H_m - P_t$ と，成分 $\dot m_r Y_{k,m}$ が入る．

## 仕事率（仮定）

2 つのスクロールの状態が違うとき（部分的な流入）の仕事率は，上の式からは導けない．次は置いた仮定で，仕様で文献の式と比べて決め直すことがある：入ってくる流れのそれぞれが，自分のよどみ状態から $p_4$ まで膨張する分の仕事を，効率 $\eta_t$ で取り出す．翼車を通らずに逆流へ回る分は，入ってくる流れから同じ割合で引く．

```math
P_t = \sum_{i \in \mathcal I} \eta_t\!\left(\frac{U}{C_{s,i}}\right)\dot m_{i \to r}\,\Delta h_{s,i}, \qquad
\dot m_{i \to r} = \dot m_i\,\frac{\dot m_r}{\sum_{j \in \mathcal I} \dot m_j}, \qquad
C_{s,i} = \sqrt{2\,\Delta h_{s,i}}
```

$U = \tfrac12 D_t\,\omega_{tc}$ は翼の先端の周速．

## 帰結

2 つのスクロールの状態が同じとき，この形は「面積 $2A_n$ の絞り 1 つと翼車の直列」になる．single-scroll（R-26）の流量の特性をこの直列の形で作れば，両者は一致する．$A_n$，$A_r$ の値と $\eta_t$ の式は仕様で決める（Q-08）．
