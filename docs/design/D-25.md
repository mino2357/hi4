# D-25：twin-scroll（考え方）

式の正本は `docs/model/eq-turbine.md` の E-W01〜E-W09．ここには式を重ねて書かない．

- **構成**：乗用車の twin-scroll（twin-entry）は，仕切り壁で軸方向に分けた 2 つのスクロールが，翼車の直前で合流する．これを，2 つの絞りが共通の空間に入り，そこから翼車を通る形で表す．
- **未知数は 1 つ**：共通の空間は気体をためないとする（E-W04）．入る流量の和は共通の空間の圧力について単調に減り，翼車の流量は単調に増えるので，圧力は 1 つに決まる．
- **干渉**：片方のスクロールに圧力の山が来て，共通の空間の圧力がもう片方のよどみ圧を超えると，逆流の枝（E-W01，E-W02）で，排気の一部がもう片方へ流れ込む．強さを決める係数は置かず，絞りと翼車の面積の比から決まる．
- **仕事率は仮定**：2 つのスクロールの状態が違うときの仕事率（E-W08）は，流量の式からは導けない．入ってくる流れのそれぞれが，自分のよどみ状態から出口の静圧まで膨張する分を，効率を掛けて取り出すと置いた．仕様で文献の式と比べて決め直すことがある．
- **帰結**：2 つのスクロールの状態が同じとき，この形は「面積が 2 倍の絞り 1 つと翼車の直列」になる．single-scroll の流量の特性（E-T07）をこの直列の形で作れば，両者は一致する（Q-08）．
