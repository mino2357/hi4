# D-05：管の離散化（考え方）

式の正本は `docs/model/eq-pipe.md`（E-P01〜E-P09）．ここには式を重ねて書かない．

- **有限体積法**：管をセルに分け，面の数値流束の差でセルの平均を進める．
- **静止の保持（well-balanced）**：$u = 0$，$p$ が一様なとき，数値流束の運動量の成分は $p$ になり，E-P02 の右辺は $-p\,(A_{i+1/2} - A_{i-1/2}) + p_i\,(A_{i+1/2} - A_{i-1/2}) = 0$．断面積が変わる管でも，静止した気体が動き出さない．断面積の項を E-P02 の形にするのはそのためである．
