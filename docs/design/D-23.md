# D-23：筒内の 2 ゾーンと，NO の反応速度（拡大 Zeldovich 機構）

筒内は 2 ゾーンにする（Q-11 の決定）．D-11 の式は，下の 2 ゾーンの式の和に当たる．

## 2 ゾーンの式

燃焼の間，筒内を未燃部（添字 $u$）と既燃部（添字 $b$）に分ける．圧力は共通で，温度は別．$\dot m_b$ は燃える速さ（未燃部から既燃部へ移る質量流量．Wiebe 関数から），$h_u$ は未燃部の比 enthalpy，$\dot Q_u$，$\dot Q_b$ は壁への熱．

```math
\begin{aligned}
\frac{d(m_u e_u)}{dt} &= -p\,\frac{dV_u}{dt} - \dot Q_u - \dot m_b\,h_u \\
\frac{d(m_b e_b)}{dt} &= -p\,\frac{dV_b}{dt} - \dot Q_b + \dot m_b\,h_u \\
V_u + V_b &= V(\theta), \qquad p_u = p_b = p
\end{aligned}
```

2 式を足すと $\dot m_b h_u$ が打ち消し合い，単一ゾーンの第一法則 $d(me)/dt = -p\,dV/dt - \dot Q$ に戻る．燃焼の前は未燃部だけ，燃焼の後は既燃部だけにする（燃え残った未燃部は，燃焼の終わりに，エネルギーと成分を保存して既燃部に混ぜる）．弁が開いている間の出入りは，その時点にあるゾーンに入れる（細部は仕様）．壁への熱の 2 つのゾーンへの配分も仕様で決める．

## 既燃部の化学

既燃部の組成は，CO と NO を反応速度の式で解き，残りの種を，その 2 つの量を拘束した化学平衡（$T_b$，$p$，元素の量から）で決める（D-24．Q-11，Q-12 の決定）．凍結のしきい値は置かない．NO の式は下，CO の式は D-24．

## 拡大 Zeldovich 機構

```math
\begin{aligned}
\mathrm{O} + \mathrm{N_2} &\rightleftharpoons \mathrm{NO} + \mathrm{N} && (1) \\
\mathrm{N} + \mathrm{O_2} &\rightleftharpoons \mathrm{NO} + \mathrm{O} && (2) \\
\mathrm{N} + \mathrm{OH} &\rightleftharpoons \mathrm{NO} + \mathrm{H} && (3)
\end{aligned}
```

仮定：(a) $\mathrm{O}$，$\mathrm{O_2}$，$\mathrm{OH}$，$\mathrm{H}$，$\mathrm{N_2}$ は平衡の濃度（添字 $e$）にある．(b) $\mathrm{N}$ は準定常（$d[\mathrm{N}]/dt = 0$）．正反応と逆反応の速度定数を $k_i^{+}$，$k_i^{-}$，濃度を $[\,\cdot\,]$ とし，平衡での片道の速さを

```math
R_1 = k_1^{+}[\mathrm{O}]_e[\mathrm{N_2}]_e = k_1^{-}[\mathrm{NO}]_e[\mathrm{N}]_e, \quad
R_2 = k_2^{+}[\mathrm{N}]_e[\mathrm{O_2}]_e = k_2^{-}[\mathrm{NO}]_e[\mathrm{O}]_e, \quad
R_3 = k_3^{+}[\mathrm{N}]_e[\mathrm{OH}]_e = k_3^{-}[\mathrm{NO}]_e[\mathrm{H}]_e
```

と置く．$\alpha = [\mathrm{NO}]/[\mathrm{NO}]_e$，$\beta = [\mathrm{N}]/[\mathrm{N}]_e$ とすると，$\mathrm{NO}$ と $\mathrm{N}$ の生成の式は

```math
\begin{aligned}
\frac{d[\mathrm{NO}]}{dt} &= R_1 - R_1\alpha\beta + (R_2 + R_3)\beta - (R_2 + R_3)\alpha \\
0 &= R_1 - R_1\alpha\beta - (R_2 + R_3)\beta + (R_2 + R_3)\alpha
\end{aligned}
```

2 式を足すと $d[\mathrm{NO}]/dt = 2R_1(1 - \alpha\beta)$．第 2 式から $\beta = \dfrac{R_1 + \alpha(R_2 + R_3)}{R_1\alpha + R_2 + R_3}$ なので $1 - \alpha\beta = \dfrac{(R_2 + R_3)(1 - \alpha^2)}{R_1\alpha + R_2 + R_3}$．したがって

```math
\frac{d[\mathrm{NO}]}{dt} = \frac{2R_1\,(1 - \alpha^2)}{1 + K\alpha}, \qquad K = \frac{R_1}{R_2 + R_3}
```

$\alpha = 1$（平衡）が安定な不動点．

## 温度と圧力が一定のときの積分

$R_1$，$K$，$[\mathrm{NO}]_e$ が定数なら変数分離できる．$\dfrac{1 + K\alpha}{1 - \alpha^2} = \dfrac{1 + K}{2(1 - \alpha)} + \dfrac{1 - K}{2(1 + \alpha)}$ を使い，$\alpha(0) = \alpha_0$ から積分すると

```math
\left[ -\frac{1 + K}{2}\ln\lvert 1 - \alpha\rvert + \frac{1 - K}{2}\ln(1 + \alpha) \right]_{\alpha_0}^{\alpha} = \frac{2R_1}{[\mathrm{NO}]_e}\,t
```

時刻 $t$ を $\alpha$ の初等関数で表す陽な表式で，$\alpha$ は単調なので 1 変数の Newton 法で求まる．緩和の時間の目安は $\tau_{\mathrm{NO}} = [\mathrm{NO}]_e/(4R_1)$ で，温度が下がると急に長くなる（凍結が式から出る）．

## 機関の中での解き方

1. $T_b$，$p$ は時間で変わるので，全体は数値で積分する．高温では $\tau_{\mathrm{NO}}$ が時間の刻みより短く硬いので，各ステップで係数を凍結して上の積分を使う（刻みによらず安定）．
2. 既燃部の体積が変わり，新しく燃えた気体（NO を含まない）が加わるので，質量分率 $Y_{\mathrm{NO}}$ で書く：$m_b\,\dfrac{dY_{\mathrm{NO}}}{dt} = M_{\mathrm{NO}} V_b \left.\dfrac{d[\mathrm{NO}]}{dt}\right\rvert_{\text{反応}} - \dot m_b\,Y_{\mathrm{NO}}$（$M_{\mathrm{NO}}$ はモル質量）．
3. NO は，元素の収支と熱物性に入れる（D-24 の拘束した平衡）．排気弁を出た後も，管と容積の中で同じ式を解く（D-24）．

## 限界

- 既燃部を 1 つの温度にすると，早く燃えた部分の高い温度を均すので，NO を少なく見積もる傾向がある．これを直すのが既燃部の多ゾーン化（P-63）．
- prompt NO と，$\mathrm{N_2O}$ を経る経路は入らない．
- 速度定数の値と出典は仕様に書く（Heywood の 11 章の表，Lavoie ほか 1970．値は未確認）．
