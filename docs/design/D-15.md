# D-15：コンプレッサ（考え方）

式の正本は `docs/model/eq-compressor.md`（E-C01〜E-C11）．ここには式を重ねて書かず，考え方と導出だけを書く．

- **準定常**：コンプレッサとタービンは，脈動の周期に比べて内部の通過の時間が短いとして，準定常の特性（map）で表す．
- **流量を状態量にする理由**：回転数が一定の線は，サージの近くで圧力比が流量の単調な関数でなくなるので，圧力比から流量を逆算できない．コンプレッサの中の気体の柱の運動方程式（E-C05．Greitzer 1976 の形）を解けば，定常では $p_2 = p_{01}\Pi_c$ になり，サージ（流量の振動と逆流）は，この式と下流の容積から現れる．
- **無次元の量で map を持つ**：流量係数 $\Phi_c$（E-C10）と揚程係数 $\Psi_c$（等エントロピーの enthalpy の上昇を $\tfrac12 U_c^2$ で割ったもの．E-C06）を使う（Jensen ほか 1991 の定義）．回転数ごとの線を 1 本の曲線にまとめられる．翼の先端の Mach 数への依存は入れていない（Jensen ほかの式は入れている．高回転で圧力比を大きく見積もる側の割り切り）．
- **曲線の形**：Moore と Greitzer（1986）の 3 次式（E-C11）．$x = \Phi_c/W - 1$ と置くと $\Psi_c = \Psi_0 + H\,(1 + \tfrac32 x - \tfrac12 x^3)$．$d\Psi_c/dx = \tfrac32 H (1 - x^2)$ なので，傾きが $0$ になるのは $x = \pm 1$．$x = -1$（$\Phi_c = 0$）で $\Psi_c = \Psi_0$，$x = 1$（$\Phi_c = 2W$）で最大の $\Psi_c = \Psi_0 + 2H$．その間（$0 < \Phi_c < 2W$）は傾きが正で，サージが起きうる側．$\Phi_c < 0$（逆流）では $\Psi_c$ がふたたび上がる．
- **圧力比**：$\Psi_c$ から等エントロピーの圧縮の出口の比 enthalpy が決まり（E-C06），同じエントロピーの条件から圧力比が決まる（E-C03）．比熱が一定なら $\Pi_c = \left[1 + \dfrac{\Psi_c\,U_c^2}{2 c_p T_{01}}\right]^{\gamma/(\gamma-1)}$．
- **仕事と効率**：翼車が気体にする仕事は Euler の式 $\Delta h_0 = \sigma_c U_c^2$（E-C07．$\sigma_c$ は slip factor．翼の後退角は入れていない）．効率は置かずに導く：$\eta_c = \Psi_c \cdot \tfrac12 U_c^2 / \Delta h_0 = \Psi_c/(2\sigma_c)$（E-C04）．仕事は流量によらず正なので，揚程係数が負になる大流量の側でも温度が破綻しない（そこでは $\eta_c < 0$．仕事をして圧力が下がる）．効率の最大はサージの境（$\Phi_c = 2W$）に来る（実物ではもう少し大流量の側）．
- **数値の例**（説明のために置いた値：$D_c = 52$ mm，$\Psi_0 = 1.04$，$H = 0.03$，$W = 0.03$，$\sigma_c = 0.85$，入口 100 kPa・298 K，比熱は一定）：160 000 rpm，0.12 kg/s で $\Pi_c = 2.40$．200 000 rpm では最大 4.57 で，大きすぎる（下の Mach 数の割り切りのため）．
- **割り切り**：軸の回転が $0$ に近いと流量係数が定義できない（扱いは仕様）．逆流のときのエネルギーの扱いは近似．
- **出典**：Moore と Greitzer の 3 次式の形と，Jensen ほかの係数の定義は，検索の結果で確かめた（もとの論文そのものは開いていない）．3 次式の性質（傾きが $0$ の位置と値）は，上のとおり自分で導いた．
