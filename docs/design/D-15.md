# D-15：コンプレッサ（考え方）

式の正本は `docs/model/eq-compressor.md`（E-C01〜E-C08）．ここには式を重ねて書かない．

- **準定常**：コンプレッサとタービンは，脈動の周期に比べて内部の通過の時間が短いとして，準定常の特性（map）で表す．map は公開されている式の形から選ぶ（Q-08．出典は D-22）．
- **流量を状態量にする理由**：回転数が一定の線は，サージの近くで圧力比が流量の単調な関数でなくなるので，圧力比から流量を逆算できない．コンプレッサの中の気体の柱の運動方程式（E-C05．Greitzer 1976 の形）を解けば，定常では $p_2 = p_{01}\Pi_c$ になり，サージ（流量の振動と逆流）は，この式と下流の容積から現れる．
- **出口の状態**：効率の定義（E-C07）から決める．比熱が一定なら $T_{02} = T_{01}\left[1 + \dfrac{\Pi_c^{(\gamma-1)/\gamma} - 1}{\eta_c}\right]$（等エントロピーの圧縮で $T_{02s}/T_{01} = \Pi_c^{(\gamma-1)/\gamma}$ だから）．
