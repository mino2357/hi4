# D-02：管の支配方程式（考え方）

式の正本は `docs/model/eq-pipe.md`（E-P01〜E-P04）．ここには式を重ねて書かない．

- **導出**：長さ $dx$ の検査体積について，質量，運動量，全エネルギーの収支を書く．断面積 $A(x)$ はゆるやかに変わり，量は断面で平均する．
- **断面積の項**：運動量の式の $p\,dA/dx$ は，傾いた側壁が気体を押す力の軸方向の成分．
- **エネルギー**：壁は動かないので，側壁の圧力と摩擦は仕事をしない．エネルギーの式には壁からの熱だけが入る．
- **成分**：流れとともに運ぶ．CO と NO は反応で変わる（D-24）．
