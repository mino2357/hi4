# D-11：シリンダの式と燃焼（考え方）

式の正本は `docs/model/eq-zone.md`（E-Z01〜E-Z13），`docs/model/eq-combustion.md`（E-X01〜E-X06），`docs/model/eq-cylwall.md`（E-Y01〜E-Y04）．ここには式を重ねて書かない．

- **4 気筒**：点火の順序 1–3–4–2 に合わせて，気筒のクランク角をずらす（位相は $0$，$540$，$180$，$360^\circ$CA）．
- **2 ゾーン**：筒内は未燃部と既燃部に分ける（Q-11 の決定．考え方と導出は D-23）．
- **発熱**：内部エネルギーが生成 enthalpy を含むので，燃焼の発熱の項は無い．
- **燃焼の期間**：層流燃焼速度 $S_L$（E-X07．Metghalchi と Keck 1982．定数は Turns の教科書の gasoline の組：$B_m = 0.2758$ m/s，$B_2 = -0.7834$ m/s，$\phi_m = 1.13$，$T_{ref} = 298$ K，$p_{ref} = 101.325$ kPa．`ice_2026` の SPEC-07 と同じ式だが，下限は外した）から，無次元の量 $G = c_m\nu_u/(B S_L^2)$ の $1/3$ 乗で決める（E-X02，E-X08，E-X09）．この形は Hires，Tabaczynski，Novak（1978，SAE 780232）の相関式 $(c_m\nu)^{1/3}(h/S_L)^{2/3}$ の形として覚えているもので，式そのものは開いて確かめられていない（検索で確かめたのは，論文があることと，乱れの尺度と層流燃焼速度から作る式であることまで）．粘性係数は一定とした．
- **`ice_2026` の期間の式を使わない理由**：乱流の速度を足す形（$S_T = S_L + C u'$）では，$S_L = 0$ でも期間が 39°CA（内径と行程が 86 mm のとき）のままで，既燃ガスの割合にほとんど依らない．
- **燃える割合**：置かない．$S_L \to 0$ で期間が無限に延び，排気弁が開くまでに燃えた割合が連続に $0$ へ近づく（部分燃焼 → 失火）．
- **数値の例**（説明のために置いた値：点火の時点の未燃部 700 K，2 MPa，3000 rpm・既燃ガスの割合 0.05 で着火遅れ 15°CA，期間 40°CA）：既燃ガスの割合 0.25 で 61°CA，0.35 で 90°CA．1000 rpm で 28°CA，6000 rpm で 50°CA．点火が上死点前 20°CA，排気弁が開くのが上死点後 130°CA のとき，燃え残りは既燃ガスの割合 0.34（6000 rpm）〜0.42（1000 rpm）から出て，0.48 で失火．
- **要検討**（利用者：「要検討かな．進めるしかない」）：式の形の出典，点火の時点の状態だけで期間を決めること，リフトの角度で燃焼を打ち切ること．
- **壁への熱**：Woschni（1967）．
