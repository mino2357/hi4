# D-14：回転系

```math
I\,\frac{d\omega}{dt} = \sum_{n=1}^{4} T_{g,n}(\theta_n) + T_{in}(\theta, \omega) - T_f - T_L
```

$T_{g,n}$ は気筒 $n$ のガス圧によるトルク，$T_{in}$ は往復質量の慣性によるトルク，$T_f$ は摩擦，$T_L$ は動力計の吸収トルク．脈動を調べる用途では，回転数を一定に保つ運転（$\omega$ を与える）を基本にし，過渡（加速，ターボラグ）ではこの式を解く．
