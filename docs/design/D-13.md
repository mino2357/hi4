# D-13：ノックの指標（考え方）

式の正本は `docs/model/eq-knock.md`（E-Q01〜E-Q03）．ここには式を重ねて書かない．

- 過給機関では点火時期がノックで制限されるので，指標を持つ．
- 未燃部の温度は，2 ゾーンの式（E-Z10）から出る．
- 自着火の遅れは Douaud と Eyzat（1978）の式の形．Livengood と Wu（1955）の積分が，燃焼の終わりより前に $1$ に達したらノックとする．
