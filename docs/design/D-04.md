# D-04：組成と熱物性（考え方）

式の正本は `docs/model/eq-thermo.md`（E-H01〜E-H07）と，`docs/model/eq-pipe.md` の E-P04，E-P08．ここには式を重ねて書かない．

- **成分**：空気（未燃），燃料の蒸気（未燃），既燃ガスのうち空気に由来する質量，既燃ガスのうち燃料に由来する質量の 4 つに，CO と NO の質量分率を加える．既燃ガスを 2 つに分けて運ぶのは，気筒や時刻によって当量比の違う既燃ガスが管の中で混ざるからで，こうすると C，H，O，N の原子の数が，移流と混合で厳密に保存する．既燃ガスの当量比は，量論空燃比 × 燃料に由来する質量 ÷ 空気に由来する質量．
- **内部エネルギー**：各成分は熱的に完全な気体で，生成 enthalpy を含む絶対値にする．燃焼の発熱は，外から加える項ではなく，成分が変わるときの内部エネルギーの差として現れる．
- **組成の決め方**：筒内でも，管と容積の中でも，CO と NO を反応速度の式で解き，残りの種を拘束した化学平衡で決める（D-24．Q-11，Q-12 の決定）．
- **温度の逆算**：内部エネルギーは温度について単調（定積比熱が正）なので，Newton 法で解ける．
