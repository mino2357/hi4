# D-18：制御と運転（考え方）

式の正本は `docs/model/eq-fuel.md`（E-N01〜E-N08），`docs/model/eq-boost.md`，`docs/model/eq-knock.md`（E-Q03），`docs/model/eq-performance.md`（E-A01〜E-A08）．ここには式を重ねて書かない．

| 制御 | 入力 | 操作量 |
| :--- | :--- | :--- |
| 負荷 | 目標のトルクまたはアクセル開度 | スロットル開度，目標の過給圧 |
| 過給圧 | サージタンクの圧力（1 サイクルの平均） | ウェイストゲートの面積 |
| 空燃比 | 吸気弁が閉じた時点の筒内の空気の質量（気筒ごと），A/F センサの出力 | 噴射量 |
| 点火時期 | MBT の探索と，ノックの指標 | 点火時期 |
| バルブタイミング | 回転数と負荷の表 | 吸気と排気のカムの位相 |

運転の種類：(1) 回転数一定の定常点（周期定常まで計算する），(2) 回転数の掃引（全負荷の性能曲線），(3) 回転数と負荷のマップ，(4) 過渡（スロットルを急に開く，急に閉じる）．
