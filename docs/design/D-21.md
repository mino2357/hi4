# D-21：コードの構成（ice_2026 に合わせる）

成果物は `ice_2026` と同じ単一の HTML（JavaScript，Canvas 2D，CSS）で，ひな形とビルドの形も同じにする．

| パス | 内容 | `ice_2026` との関係 |
| :--- | :--- | :--- |
| `src/core.js` | 物理モデル（管，容積，シリンダ，接続の要素，過給機，ECU，動力計），ソルバ，項目定義表（DOM 非依存） | 筒内，熱物性，弁，オリフィス，回転系は引き継ぐ．吸排気は 1 次元に置き換える |
| `src/plot.js` | グラフの軸とレイアウト，系統図，$x$–$t$ 線図 | 軸と自動レンジは引き継ぐ |
| `src/doc.js` | 解説タブ（式の解説，記号表），埋め込んだ文書の表示 | 形を引き継ぐ |
| `src/tests.js` | アプリ内テストとシナリオ（「検証」タブ） | 形を引き継ぐ．項目は D-20から作る |
| `src/ui.js`，`src/style.css`，`src/index.tpl.html` | 画面，入力，ループ | 形を引き継ぐ |
| `src/build.py`，`tests/headless.js`，`tools/dev/` | ビルド，段階 2 の検証，開発用の道具 | 移して直す |

計算の作り方の注意（JavaScript で 1 次元の解法を回すため）：

1. セルの状態は，量ごとの `Float64Array`（管をつないだ 1 本の配列と，管ごとの始まりの添字）に持つ．時間積分の内側のループで配列やオブジェクトを作らない（`ice_2026` の `docs/report_alloc.md` と同じ考え方）．
2. 熱物性の表は有限の添字だけで読む（`ice_2026` の REQ-13 の 19）．有限でない値が出たら，状態にせず計算を止めて知らせる．
3. 画面の描画と計算を分ける：計算はクランク角で進め，描画は記録した波形を読む．実時間は求めない（Q-02 の決定）．計算が遅くても画面が止まらないようにする．
4. 同じ処理系で結果がビット単位で再現すること（`ice_2026` の `bitcheck.js`）を保つ．

hi4 のコードはすべて新しく書き，`ice_2026` のコードは移植しない（Q-09 の決定）．上の表の「引き継ぐ」は，モデルの式と形を参考にするという意味である．
