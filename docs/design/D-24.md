# D-24：反応速度で解く種（CO，NO），拘束した平衡，管の中の反応

利用者の決定（Q-11，Q-12）：凍結のしきい値は置かない．CO と NO は反応速度の式で解き，元素の収支とエネルギーに厳密に入れる．筒内だけでなく，管と容積の中でも同じ式を解く（排気管の中の酸化．P-64）．

**式の正本は `docs/model/eq-chem.md`（E-R01〜E-R05）．ここは導出と考え方で，食い違ったら式の正本が正しい．**

## 組成の持ち方

運ぶ量は，D-04 の 4 成分（未燃の空気，燃料の蒸気，既燃ガスのうち空気に由来する質量，既燃ガスのうち燃料に由来する質量）に，CO の質量分率 $Y_{\mathrm{CO}}$ と NO の質量分率 $Y_{\mathrm{NO}}$ を加えたもの．反応に加わる元素（C，H，O，N）の量は，燃料の蒸気を除く 3 成分から決まる（未燃の空気も入る．吹き抜けた空気の酸素が，排気の CO を酸化できる）．燃料の蒸気（未燃の炭化水素）は，この式では反応しない．

## 拘束した平衡

その場所の温度 $T$，圧力 $p$，元素の量 $b_j$ と，$n_{\mathrm{CO}}$，$n_{\mathrm{NO}}$ を与えて，残りの種（$\mathrm{CO_2}$，$\mathrm{H_2O}$，$\mathrm{N_2}$，$\mathrm{O_2}$，$\mathrm{H_2}$，$\mathrm{H}$，$\mathrm{O}$，$\mathrm{OH}$）のモル数を

```math
\min_{n}\; G(T, p, n) \qquad \text{subject to} \qquad \sum_i a_{ji} n_i = b_j, \quad n_{\mathrm{CO}},\ n_{\mathrm{NO}} \text{ は与えた値}, \quad n_i \ge 0
```

で決める（$G$ は Gibbs の自由エネルギー，$a_{ji}$ は種 $i$ の 1 分子が含む元素 $j$ の原子の数）．内部エネルギーと気体定数は，この組成（CO と NO を含む）から求める．CO や NO が生成，酸化すると，生成 enthalpy の差が温度に現れる．温度が低い所では，残りの種は $\mathrm{CO_2}$，$\mathrm{H_2O}$，$\mathrm{N_2}$，$\mathrm{O_2}$，$\mathrm{H_2}$ だけになる．計算の仕方（表か，その場で解くか）は Q-13．

## 反応速度の式

基準にする平衡の濃度（添字 $e$）は，同じ $T$，$p$，$b_j$ での，拘束しない平衡（CO と NO を含む 10 種）の値．

NO は D-23 の式．CO は，$\mathrm{CO} + \mathrm{OH} \rightleftharpoons \mathrm{CO_2} + \mathrm{H}$（速度定数 $k_a^{\pm}$）と $\mathrm{CO_2} + \mathrm{O} \rightleftharpoons \mathrm{CO} + \mathrm{O_2}$（$k_c^{\pm}$）について，CO 以外を平衡の濃度に置くと

```math
\frac{d[\mathrm{CO}]}{dt} = (R_a + R_c)\left(1 - \frac{[\mathrm{CO}]}{[\mathrm{CO}]_e}\right), \qquad
R_a = k_a^{+}[\mathrm{CO}]_e[\mathrm{OH}]_e, \quad R_c = k_c^{-}[\mathrm{CO}]_e[\mathrm{O_2}]_e
```

導出：$d[\mathrm{CO}]/dt = -k_a^{+}[\mathrm{CO}][\mathrm{OH}]_e + k_a^{-}[\mathrm{CO_2}]_e[\mathrm{H}]_e + k_c^{+}[\mathrm{CO_2}]_e[\mathrm{O}]_e - k_c^{-}[\mathrm{CO}][\mathrm{O_2}]_e$．平衡では正と逆が釣り合うので $k_a^{-}[\mathrm{CO_2}]_e[\mathrm{H}]_e = R_a$，$k_c^{+}[\mathrm{CO_2}]_e[\mathrm{O}]_e = R_c$．代入してまとめる．

係数を一定とすると線形で，$\gamma_{\mathrm{CO}} = [\mathrm{CO}]/[\mathrm{CO}]_e$ について

```math
\gamma_{\mathrm{CO}}(t) = 1 + \big(\gamma_{\mathrm{CO}}(0) - 1\big)\exp\!\left(-\frac{t}{\tau_{\mathrm{CO}}}\right), \qquad \tau_{\mathrm{CO}} = \frac{[\mathrm{CO}]_e}{R_a + R_c}
```

各ステップで係数を凍結してこの式で進める（刻みによらず安定）．$\tau_{\mathrm{CO}}$ と $\tau_{\mathrm{NO}}$ は温度が下がると急に長くなるので，組成は式から自然に変わらなくなる（しきい値は置かない）．

## 管と容積の中

管のセルと容積でも，流れの 1 ステップの後に，その場所の $T$，$p$，組成で上の式を進める（質量と全エネルギーは変えず，$Y_{\mathrm{CO}}$，$Y_{\mathrm{NO}}$ と，それに伴う温度だけが変わる）．吹き抜けた空気とリッチな排気が混ざった所では $[\mathrm{CO}]_e$ が小さくなり，温度が高ければ CO が酸化して発熱する．

## 限界

- OH，O，H を平衡の濃度に置くので，膨張の後半でラジカルが平衡より多く残ることによる CO の酸化の違いは表さない．
- 未燃の炭化水素（HC）の生成と酸化は，この式に入っていない（すきまと油膜によるものは，現象の候補 P-65）．
- 混ざり方は 1 次元（断面の中は一様）なので，吹き抜けた空気と排気の混合の速さは，実際と違う．
- 速度定数の値と出典は仕様に書く（Heywood の 11 章．値は未確認）．
