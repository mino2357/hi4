# D-08：圧縮性のオリフィス（考え方）

式の正本は `docs/model/eq-orifice.md`（E-O01，E-O02）．流量は $\dot m = A_t\,\dfrac{p_0}{\sqrt{R T_0}}\,\Psi\!\left(\dfrac{p_d}{p_0}\right)$（$A_t$ は有効な面積，$p_0$，$T_0$ は上流のよどみ状態，$p_d$ は下流の静圧）．

- **導出**：上流から喉までを等エントロピー，喉の圧力を下流の圧力に等しいとする．エネルギーの式 $c_p T_0 = c_p T_t + \tfrac12 u_t^2$ と，等エントロピーの関係 $T_t/T_0 = r^{(\gamma-1)/\gamma}$，$\rho_t/\rho_0 = r^{1/\gamma}$ から $u_t$ を求め，$\dot m = \rho_t u_t A_t$ に入れる．
- **チョーク**：圧力比が臨界の値以下では喉が音速で，流量は下流の圧力によらない．
- **使う所**：ウェイストゲート，再循環弁，twin-scroll の絞りと翼車．
