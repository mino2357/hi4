# D-16：タービンとウェイストゲート（考え方）

式の正本は `docs/model/eq-turbine.md`（single-scroll は E-T01〜E-T10）と `docs/model/eq-wastegate.md`（E-G01）．ここには式を重ねて書かない．

- **準定常の要素**：タービンは，入口の容積（よどみ状態）と出口の容積（静圧）の間の要素．
- **流量**：スクロールの出口の絞りと，翼車の絞りの直列で表す（E-T07，E-T10）．間の空間の圧力 $p_m$ は，2 つの絞りの流量が等しいことから決まる．絞りの流量は $p_m$ について単調に減り，翼車の流量は単調に増えるので，$p_m$ は 1 つに決まる．twin-scroll（D-25）と同じ形で，2 つのスクロールの状態が同じなら一致する．タービンを 2 つの絞りの直列で表すやり方は，文献にある（Galindo ほか 2018，Zhu ほか 2015．検索の結果で見ただけで，論文は開いていない）．
- **割り切り**：絞りと翼車の有効な面積を一定とした．実際には，回転数（遠心力）と速度比で変わる．流量は回転数によらない．
- **効率**：速度比 $\nu = U/C_s$ の 2 次式（E-T06）．$\nu = \nu_{opt}$ で最大．広く使われる形だが，出典はこの場では開いて確かめられなかった（開こうとした報告書のホストに，この環境からつながらなかった）．
- **瞬時値の積分**：脈動する流れでは，膨張比と流量が 1 サイクルの中で大きく変わり，仕事率の瞬時値の大半は blowdown の山で生じる．これを瞬時値のまま積分する．
- **限界**：脈動する流れの下で，効率が準定常の値からずれることは扱わない（スクロールを 1 次元の管として解く形は R-31）．
- **ウェイストゲート**：同じ 2 つの容積の間のオリフィス（D-08）で，面積を制御する．
