# D-16：タービンとウェイストゲート（考え方）

式の正本は `docs/model/eq-turbine.md`（single-scroll は E-T01〜E-T09）と `docs/model/eq-wastegate.md`（E-G01）．ここには式を重ねて書かない．

- **準定常の要素**：タービンは，入口の容積（よどみ状態）と出口の容積（静圧）の間の要素．膨張比に対して流量は単調なので，オリフィスと同じに扱える．
- **瞬時値の積分**：脈動する流れでは，膨張比と流量が 1 サイクルの中で大きく変わり，仕事率の瞬時値の大半は blowdown の山で生じる．これを瞬時値のまま積分する．
- **限界**：脈動する流れの下で，効率が準定常の値からずれることは扱わない（扱うのは P-28）．
- **ウェイストゲート**：同じ 2 つの容積の間のオリフィス（D-08）で，面積を制御する．
- **twin-scroll**：D-25．
