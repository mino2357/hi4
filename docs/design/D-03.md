# D-03：壁面の摩擦と熱伝達（考え方）

式の正本は `docs/model/eq-wall.md`（E-F01〜E-F05）．ここには式を重ねて書かない．

- **摩擦係数**：滑らかな円管の層流と，乱流の Blasius の式．粗さと曲がりは，管ごとの倍率で表す．
- **触媒の担体**：開口率を掛けた断面積と，セルの水力直径を持つ管として扱い，層流の $f\,Re$ をセルの形の値（正方形で $14.2$）にする．
- **熱伝達率**：Reynolds–Colburn の相似 $St = \dfrac{f}{2}Pr^{-2/3}$ で摩擦係数から決める．脈動する流れでは定常の式より熱伝達が大きいことが知られているので，管ごとの倍率を設ける．流速が $0$ に近いときの下限（層流の Nusselt 数 $3.66$）を置く．
- **壁温**：管ごとの設定値（R-05）か，壁の熱容量の式（R-10）．
- **インタークーラ**：水力直径が小さく，壁温が冷却側の温度に等しい管として表す（R-28）．
