# D-07：容積と合流部（考え方）

式の正本は `docs/model/eq-volume.md`（E-V01〜E-V10）と `docs/model/eq-junction.md`（E-J01，E-J02）．ここには式を重ねて書かない．

- **容積は流速を持たない**：流れ込んだ運動エネルギーは内部エネルギーになる．出ていく面では容積の値，入ってくる面では面の向こう側の値（風上）を運ぶ．
- **保存**：管端の面の流束を，そのまま容積の式に使う．同じ数を管のセルから引き，容積に足すので，系の全体の質量，エネルギー，各成分の質量が，丸め誤差の範囲で保存する．
- **合流部を容積で表す割り切り**：流れ込んだ運動量の向きの情報が失われる．定常の流れでは動圧 1 つ分の全圧の損失に相当し，急拡大の損失には近いが，なめらかな合流では損失を大きく見積もる．pulse converter のように運動量の向きを使う形は表せない．
- **向きを扱う形**：流れの向きと枝管の角度による損失係数を持つ（Bassett ほか 2003．式は仕様で決める）．既定はこの形（R-08）．
- **寸法の制限**：容積が小さすぎると，陽な時間積分が不安定になる．つながるセルの体積の和を下限にし，これより小さい室は，隣の管に含める．
