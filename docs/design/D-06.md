# D-06：数値流束，再構成，時間積分，正値の保持（考え方）

式の正本は `docs/model/eq-pipe.md`（E-P10〜E-P12）．ここには式を重ねて書かない．

- **数値流束**：HLLC（Toro ほか 1994）．波の速さの見積もりと，左右の状態の圧力とエネルギーだけを使うので，比熱が温度で変わる気体にそのまま使える．接触不連続（温度と組成の境目）を保つ．
- **再構成**：原始変数の区分線形（MUSCL）．勾配の制限は minmod を既定，van Albada を選択肢とする．成分は $[0, 1]$ と和が $1$ であることを保つように制限する．
- **時間積分**：3 段 3 次の SSP Runge–Kutta を既定，MUSCL–Hancock を速さのための選択肢とする．摩擦と熱伝達は陽に扱う（水力直径が小さい管で硬くなる場合は，その項だけ陰に解く）．容積，シリンダ，軸も，同じ刻みで，同じ段の中で進める（面を通った質量とエネルギーが，両側で同じ値になる）．
- **格子**：格子の幅は管ごとに設定する．結果が格子によらないことは，幅を半分にして確かめる（D-20）．
- **正値の保持**：再構成した値の密度や圧力が負になる面では，再構成を 1 次に落とす．それでもセルの値が負になったときは，計算を止めて場所と状態を報告する（値を黙って丸めない）．
- **組成の境目での圧力の乱れ**：Q-10．
