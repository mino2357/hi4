# G-03：前提と制約（`ice_2026` の要件定義書 2 節）

| # | `ice_2026` の制約 | hi4 |
| :--- | :--- | :--- |
| C-1 | 単一の HTML ファイル（JavaScript，Canvas 2D，CSS）．ネットワークなしで動く | 同じ |
| C-2 | スマートフォンのタッチ操作だけで全機能を使える | 同じ（主対象の環境も同じ：Galaxy S26+ の Chrome，縦持ち） |
| C-3 | 内部は SI，画面の圧力は Pa 系 | 同じ |
| C-4 | 質量，既燃ガス，エネルギーの収支が閉じる | 同じ．管と合流部を含めた系の全体で閉じる |
| C-5 | 決定性 | 同じ |
| C-6 | 全要件に対応するテストを持ち，アプリの「検証」タブから実行できる | 同じ |
| C-7 | 結果を実機に合わせ込まない．経験定数は値と決め方を仕様書に書く | 同じ |
| C-8 | 第三者の著作物を埋め込まない | 同じ |

`ice_2026` の目的にある「実時間に可視化」は引き継がない：実時間は求めず，計算はクランク角で進め，表示はスローモーションにする（Q-02 の決定）．
