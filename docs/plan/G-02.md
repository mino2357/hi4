# G-02：`ice_2026` から引き継ぐ進め方と文書

| 事項 | `ice_2026` での定め | hi4 |
| :--- | :--- | :--- |
| 作業の順 | 要件（REQ）が先．利用者に見せるのは要件の差分だけ．承認の後に仕様（SPEC，TEST），用語の定義集．利用者が指示するまで実装しない（CLAUDE.md） | 同じ（`CLAUDE.md`） |
| 文書の体系 | 要件定義書，仕様書，画面の文書，用語の定義集．REQ-nn／SPEC-nn／TEST-nn は同じ番号が対応．見出しごとの断片のファイル，索引は自動生成 | 同じ．hi4 の番号は別の形にして，`ice_2026` の番号と混ざらないようにする（要件は R-nn．「REQ-nn」と書いたら `ice_2026` の項目）．要件より前の段階の文書（現象，設計の案，未決，企画）は `docs/INDEX.md` の体系で持つ |
| テスト | 受入基準は TEST の項目で判定できる形．不具合はテストを先に書き，直す前に FAIL することを実行して確かめる | 同じ |
| 検証の段階 | 段階 1（影響するテストだけ），段階 2（全部） | 同じ |
| 表記 | 句読点は「，」「．」．圧力は Pa 系，トルクは N·m．定着していない術語は英語 | 同じ |
| 変更の記録 | 変更 1 件を 1 ファイル（`docs/changes/`） | 同じ |
