# G-05：対象の機関（既定値の案）

既定値でよいかは Q-03．

架空の機関で，どれも設定で変えられるようにする．性能の数値は計算の結果で，要件にはしない（G-03 の C-7）．

| 項目 | 値 |
| :--- | :--- |
| 形式 | 直列 4 気筒，4 ストローク，火花点火，DOHC 4 弁 |
| 内径 $B$ × 行程 $S$ | $84.0\ \text{mm} \times 90.0\ \text{mm}$ |
| 行程容積 | 1 気筒 $V_d = \dfrac{\pi}{4}B^2 S = 498.8\ \text{cm}^3$，合計 $1995\ \text{cm}^3$ |
| 連接棒の長さ $l$ | $145\ \text{mm}$ |
| 圧縮比 $\varepsilon$ | $10.0$ |
| 点火の順序 | 1–3–4–2（間隔 $180^\circ$CA） |
| 燃料の供給 | 筒内直接噴射 |
| 過給 | 排気タービン式過給機 1 基 |
| 燃料と熱物性 | `ice_2026` の REQ-29 と同じ（量論空燃比 $14.503$） |
