## したこと

1. **承認のしるし**（道具）：要求を承認したときに，その要求が名指しする式と，確かめることの行から作ったハッシュを `docs/model/approved.json` に書く．承認の後で式や行が変わると，`npm run check` が，承認を確かめ直す要求を知らせる．はじめは式のファイルの単位で数えたところ，壁の式のファイルに式を 1 本足しただけで，関係の無い要求 4 件まで古いと出た（7 件）．要求が名指しする式だけを数えるように直し，2 件になった．
2. **触媒の式**：`docs/model/eq-catalyst.md`（E-CA02〜E-CA10．物質移動係数，表面の釣り合い，表面の反応の速さ，気体の成分の出入り，持ち去る全 enthalpy，酸素の吸蔵，浄化率）と，`eq-wall.md` の E-U02（担体の温度）．
3. **承認済みの式に足した項**：管のエネルギーの式 E-P03 に，表面との出入りが持ち去る全 enthalpy $\dot q_{E,cat}$．成分の式 E-P04 に，表面との出入り $\dot\omega_{k,cat}$．どちらも触媒の外では $0$．気体の成分に「酸素の過不足」を加えた（酸素の吸蔵で，空気に由来する質量の中の酸素と窒素の比が保てなくなるため）．
4. **要求** R-32（触媒の暖機と熱容量），R-33（三元触媒の反応と，酸素の吸蔵）を「案」で書いた．現象の候補 P-65（すきまと油膜による未燃の炭化水素）を加えた．
5. 承認のしるしが知らせた R-01 と R-06 を「案」に戻した（R-06 は本文も変えた：酸素の過不足）．

## 書いている途中に見つけた誤り

- 道具が検出したもの：量の番号 `C_s` が過給の量（等エントロピーの膨張の速度）と重なっていた．担体の温度の式を触媒の節点に置いたが，定める量（壁温）は壁の節点のものだった．
- 道具が検出しなかったもの：担体の式に別の熱伝達率（Nusselt 数から）を置き，気体の側は管の壁の式の熱伝達率を使っていた．同じ熱のやりとりに 2 つの係数があり，気体が失う熱と担体が受ける熱が合わない．名前の違う量なので，構造の検査は通っていた．担体の式が管の壁の熱流束 $q_w$ をそのまま使うように直した．

## 決めたこと（式の形にするとき）

- 反応の発熱は，別に加える項にしない．成分が気体から表面へ移るときに持ち去る全 enthalpy と，生成物が戻すものの差が，担体に入る．
- 表面に成分を溜めない（表面の釣り合いは代数の式）．
- 水素は，拘束した平衡に従う（酸素があれば残らない）ので，表面の反応には入れない．
- 未燃の炭化水素は，燃料の蒸気の成分で表す．
