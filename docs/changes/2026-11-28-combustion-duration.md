# 2026-11-28 燃焼の期間と燃える割合の式（式の形が決まっていなかったもののうち 2 本）

## 指示

利用者：案（数値と図で示した）に書き換えてよいか：「はい．ただ要検討かな．進めるしかない」．

## したこと

- 層流燃焼速度 E-X07（Metghalchi と Keck 1982．`ice_2026` の SPEC-07 と同じ式と定数．下限は外した），無次元の量 E-X08，着火遅れ E-X09 を加えた．
- 燃焼の始まり E-X01 に着火遅れを入れた．燃焼の期間 E-X02 を $C_b G^{1/3}$ にした．
- 燃える割合 E-X03 は，置く式をやめ，燃焼が終わる（Wiebe 関数が終わるか，排気弁が開くか，早いほう）までに燃えた割合（出力）にした．E-X06 から $\eta_b$ を外した．
- 確かめること：K-78 の条件を「層流燃焼速度を固定」に直した．K-136（層流燃焼速度の基準の点と $0$ になる点，燃える割合が連続に $0$ へ近づくこと）を加えた．
- 式が変わったので，R-13 と R-14 を「案」に戻した．Q-14 を決定にした．

## 数値にして確かめたこと

- 説明のための値（内径と行程 86 mm，点火の時点の未燃部 700 K・2 MPa，$\phi = 1$，3000 rpm・既燃ガスの割合 0.05 で着火遅れ 15°CA・期間 40°CA になる定数）で計算した．
- 層流燃焼速度：既燃ガスの割合 0.05 で 0.94 m/s．$0$ になるのは，既燃ガスの割合 0.48，$\phi < 0.54$，$\phi > 1.72$．
- 期間（3000 rpm）：既燃ガスの割合 0.25 で 61°CA，0.35 で 90°CA．既燃ガスの割合 0.05 で，1000 rpm 28°CA，6000 rpm 50°CA．
- 燃え残り（点火が上死点前 20°CA，排気弁が開くのが上死点後 130°CA）：既燃ガスの割合 0.34（6000 rpm）〜0.42（1000 rpm）から出て，0.48 で失火．
- `ice_2026` の期間の式（乱流の速度を足す形）は，$S_L = 0$ でも期間が 39°CA で，既燃ガスの割合に鈍いので使わなかった．
- この計算では粘性係数に Sutherland の式の 700 K の値を使った．式（E-X08）では一定の設定値にしたので，定数 $C_d$，$C_b$ の値はその分だけ変わる（期間の値は同じに合わせられる）．

## 出典の確かめ方

- 層流燃焼速度：`ice_2026` の SPEC-07 が講義ノートで確かめた式と定数（この場では開き直していない）．
- 期間の形：Hires，Tabaczynski，Novak（1978，SAE 780232）の相関式の形として覚えているもの．検索で確かめたのは，論文があることと，乱れの尺度と層流燃焼速度から作る式であることまで．式そのものは開いて確かめられていない．
