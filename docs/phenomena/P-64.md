# P-64：排気管の中の酸化（CO の酸化と発熱）

## 見えるもの

排気弁を出た後の CO の減り方．吹き抜けた空気とリッチな排気が排気管で混ざって酸化し，タービンの入口の温度が上がる様子．

## 要るもの

管と容積の中で，筒内と同じ反応速度の式（CO，NO）を解くこと．組成の変化に伴う発熱（D-24）．

## 採らないとき

反応は筒内だけで解き，排気弁を出た組成のまま管を運ぶ．
