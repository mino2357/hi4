# P-25：コンプレッサのサージ

## 見えるもの

流量と圧力の振動，逆流，map の上の軌跡．

## 要るもの

逆流の側の特性と，その検査（流量を状態量に持つ式は D-15 にある）．

## 採らないとき

サージ線より小流量の側の動きは表さない（そこへ入ったことを知らせるだけにする）．P-27 を採れない．
