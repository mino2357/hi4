# P-33：scavenging（overlap の間に新気が排気側へ吹き抜ける）

## 見えるもの

overlap の間に吹き抜けた空気の質量．筒内の当量比と排気の当量比のずれ．

## 要るもの

吹き抜けた質量の集計．

## 採らないとき

吹き抜けは計算には現れても，量として表示しない．
