# P-05：新気と既燃ガスの境目，温度の境目の移動

## 見えるもの

管の中の既燃ガスの割合と温度の分布．吹き返した既燃ガスが吸気管のどこまで戻るか．

## 要るもの

成分の移流，接触不連続を保つ流束．

## 採らないとき

管の中の組成を追わない（吸気側は空気，排気側は一様な既燃ガスとみなす）．P-32，P-33，P-55 を採れない．
