# P-66：機関から出る NO

## 見えるもの

既燃部での NO の生成と，膨張の途中で反応が遅くなって量が変わらなくなる様子．排気弁を出る NO の量と，当量比や点火時期への依存．

## 要るもの

拡大 Zeldovich 機構の反応速度の式（D-23）．NO を，元素の収支とエネルギーに入れた拘束した平衡（D-24）．

## 採らないとき

NO は運ばない．既燃ガスは CO だけを反応速度の式で解く形になる．
