# P-14：twin-scroll による気筒の群の分離

## 見えるもの

気筒 1・4 と気筒 2・3 の排気を分けたときの，干渉の減り方．

## 要るもの

タービンの入口を 2 つに分ける．部分的な流入の特性（近似）．

## 採らないとき

single-scroll だけになる．
