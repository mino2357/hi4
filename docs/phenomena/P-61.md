# P-61：A/F センサ（空燃比センサ）の応答

## 見えるもの

排気管の中のセンサの位置を通る気体の当量比（気筒ごとの排気が順に通るので，1 サイクルの中で変わる）と，それに対するセンサの出力．出力は，気体がセンサに届くまでの遅れ（管の中の移流で自然に出る），センサ自身の応答の遅れ，圧力の脈動による出力のずれを含む．

## 要るもの

センサの位置の気体の組成（P-05 の成分の追跡）から出力を作るセンサのモデル：応答の遅れ（一次遅れなど），圧力への依存，リッチの側での CO と H₂ への感度．どこまで入れるかは要件で決める．タービンの上流に置くか下流に置くかを設定できること（設計の案はまだ無い）．

## 採らないとき

空燃比の制御は，筒内の空気の質量から噴射量を決める前向きの計算だけになる（排気の組成を測って戻す制御は無い）．P-62 を採れない．
