# P-63：既燃部の温度の成層（既燃部の多ゾーン化）

## 見えるもの

早く燃えた部分ほど温度が高いこと．それによる NO の量の増加．

## 要るもの

既燃部を，燃えた順の層に分ける式．層ごとの平衡と，NO の反応速度の式（D-23 の式を層ごとに使う）．

## 採らないとき

既燃部は 1 つの温度（R-12）．NO を少なく見積もる傾向が残る．
