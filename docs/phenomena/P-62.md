# P-62：気筒別の燃料噴射の制御

## 見えるもの

気筒ごとの空燃比のずれ（P-12 の気筒ごとの充填の差，噴射弁のばらつきの設定，P-33 の吹き抜け）と，合流部の 1 本の A/F センサの出力から気筒ごとのずれを推定して，気筒ごとに噴射量を補正する様子．補正の前後の，気筒ごとの当量比の差．

## 要るもの

センサの出力をクランク角に同期して取り，どの気筒の排気かを割り当てる推定の方法，気筒ごとの補正の制御則，噴射弁のばらつきの設定（設計の案はまだ無い）．

## 採らないとき

噴射量は，全気筒に同じ補正だけになる．気筒ごとの空燃比の差は，計算には現れても補正されない．
