# 量（管，熱物性，壁，管端，オリフィス）

セルの量はセル $i$ ごと，面の量は面 $i+\tfrac12$ ごと．成分の添字 $k$ は，空気，燃料の蒸気，既燃ガスの空気由来，既燃ガスの燃料由来，CO，NO．
