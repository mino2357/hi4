# 仮定の組

「決定」は，全体で 1 つの値に決めたもの（式が違う値を前提にしていたら誤り）．「切替」は，設定で選ぶ別の形（それぞれの形で，式と量の対応を別に調べる）．

| 組 | 種類 | 値 | 選んだ値 | 根拠 |
| :--- | :--- | :--- | :--- | :--- |
| コンプレッサの流量 | 決定 | 状態量／圧力比から逆算 | 状態量 | R-25 |
| タービンの特性 | 決定 | 準定常／非準定常 | 準定常 | R-26 |
| 定常点の出発点 | 決定 | 簡易計算／既定値 | 簡易計算 | R-27 |
| タービンの入口 | 切替 | single／twin | – | R-26，R-29 |
| 組成 | 決定 | 4 成分と CO，NO／4 成分だけ | 4 成分と CO，NO | R-06 |
| 管の中の反応 | 決定 | CO と NO の反応速度／なし | CO と NO の反応速度 | R-06 |
| 管端のモデル | 決定 | 特性曲線と定圧モデル／流束だけ | 特性曲線と定圧モデル | R-03 |
| 合流部 | 切替 | 向きを扱う／容積 | – | R-08 |
| 壁温 | 切替 | 固定／熱容量 | – | R-05，R-10 |
| 筒内のゾーン | 決定 | 2 ゾーン／単一／既燃を多ゾーン | 2 ゾーン | R-12，Q-11 |
| 既燃ガスの化学 | 決定 | 拘束した平衡と反応速度／全温度域で平衡／完全燃焼 | 拘束した平衡と反応速度 | R-13，Q-11，Q-12 |
| 燃焼の進み方 | 決定 | Wiebe 関数／火炎伝播のモデル | Wiebe 関数 | R-13 |
| ガス交換の混ざり方 | 決定 | 完全混合／完全置換／短絡を持つ 2 ゾーン | 完全混合 | R-15 |
| サイクル変動 | 決定 | 決定論的な結合／乱数 | 決定論的な結合 | R-14 |
| 回転 | 切替 | 一定／自由 | – | R-19 |
| 気筒別の補正 | 切替 | 切／入 | – | R-24 |
| タービンのスクロール | 切替 | 0 次元／1 次元 | – | R-26，R-31 |
