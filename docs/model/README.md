# 式と量で持つ要求（試作：過給の部分）

要求どうしの矛盾をすぐ検出できるように，要求の中身を「量」「式」「確かめること」に分けて持つ試作．範囲は過給（R-25〜R-29）だけ．うまく働けば全体に広げ，働かなければやめる（利用者の決定．2026-11-28）．R-25，R-26，R-27，R-29 は，式を指す薄い形に書き直した（R-28 のインタークーラは，式が管の側にあるので，まだ前の形）．

| ファイル | 中身 | 機械が読む所 |
| :--- | :--- | :--- |
| `tree.md` | 置き場所の木（節点） | 字下げの箇条書き |
| `assumptions.md` | 仮定の組．「決定」は全体で 1 つの値，「切替」は設定で選ぶ別の形 | 表 |
| `quantities-turbo.md` | 量：番号，記号，意味，単位，種類，節点 | 表 |
| `eq-*.md` | 式．1 本ごとに，定める量，使う量，仮定，切替 | 見出しと箇条書き |
| `checks-turbo.md` | 確かめること（式から機械的に決まらないものだけ）：要求，種類，対象，判定 | 表 |
| `REPORT.md` | 検査の結果（自動生成．手で書き換えない） | – |

## 決まり

1. **正本は 1 つ**：式はここの `eq-*.md` だけに書く．設計の案（D）は考え方だけ，要求（R）は「どの式で計算するか」と，式で書けない要求だけを書く．
2. **検査は最小にする**（利用者の指示．2026-11-28）．検査は 3 種類だけ．
   - **表の行**（`checks-*.md`）：その式の誤りを見分けるように作った検査．「対象」には，その検査が見分ける式だけを書く（たどって通るだけの式は書かない）．
   - **保存**：系の全体で 3 つ（質量，エネルギー，原子）．釣り合いの式（`kind: 釣り合い`）と，状態量を定める式の全部が対象．部品ごとには作らない．判定は A．
   - **式との一致**：どの行の対象にもならず，保存の対象でもない式にだけ，道具が自動で付ける（基準の値を 1 組入れて，式の値と比べる）．判定は A．
3. **重なりを知らせる**：同じ要求・種類・対象の行が 2 つ以上あれば，道具が知らせる（1 つにまとめられないかを見る）．
4. 利用者に承認をお願いするのは，式，仮定，3 の基準．

**未知**（その節点の式が定める），**状態**（時間微分の式が定める），**流れ**（節点の間を移る量．式が定める），**入力**（試作の範囲の外で定まる），**設定**（利用者が与える），**許容**（判定の C に使う，利用者が決めるしきい値）．

道具 `npm run model` が調べること：

1. 式が使う量と定める量が，量の表にある．
2. どの式も，量を 1 つだけ定める．定める量の節点が，式の節点と同じ．
3. 未知，状態，流れの量は，ちょうど 1 本の式が定める（切替の別の形どうしは別に数える）．入力，設定，許容の量は，どの式も定めない．
4. 節点と切替の形ごとに，式と量の 2 部グラフの最大マッチングを取り，相手のいない式（多すぎる）と，相手のいない量（足りない）を示す．
5. 式が前提にする仮定が，「決定」の組の選んだ値と同じ．
6. 確かめること：対象の式がある．判定は A，B，C 名前，– のどれか．C の名前は量の表の「許容」にある．同じ対象と種類に，違う設定が掛かっていれば並べて示す．式のファイルの `source` にある要求の本文が，その式のファイルを指している．
7. 連立して解く組（互いに使い合う量の輪）を示す．
8. 検査の数（表の行，保存，式との一致）と，式ごとの対象を `REPORT.md` の 4 節に出す．

## 変更するとき

1. 式を変える：`eq-*.md` の 1 か所を直す（正本は 1 つ）．量を加えるなら量の表に 1 行．
2. `npm run model`：構造の誤り（式が多すぎる，足りない，仮定の食い違い）がその場で出る．
3. `npm run model -- --tests 式の番号`：やり直す検査と，承認を確かめ直す要求が出る（対象に書いた行だけ．保存は，釣り合いの式を変えたときだけ）．
4. `npm run model -- --impact 量の番号`：その量を使う式が出る．
5. 承認用のページは `npm run model -- --page` で作り直す．

調べないこと：式の中身（数の上で両立するか），単位（量の表に単位はあるが，式の次元の検査はまだ無い），保存の対（流れの量の出る側と入る側の対応は，表に書いてあるだけで，容積の側の式が試作の範囲の外にある）．
