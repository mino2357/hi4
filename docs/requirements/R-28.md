# R-28：インタークーラ

## 要求

インタークーラを，水力直径が小さく，壁温が冷却側の温度に等しい管（束）として置き，吸気の冷却と圧力損失が現れること．圧力波が通り抜けること（0 次元の要素にしない）．冷却の効率を記録すること．

## 受入基準

判定値は実装の前の案で，実行して確かめていない．値の根拠は，仕様のテスト項目に書く．

1. **冷却**：定常の流れ（Mach 数 $0.1$ 以下）で，出口と入口の温度が $\dfrac{T_{out} - T_w}{T_{in} - T_w} = \exp\!\left(-St\,\dfrac{4L}{D_h}\right)$ を相対 $2\%$ 以内で満たす（R-05 の受入基準 4 を，インタークーラの寸法で）．
2. **圧力損失**：定常の流れの圧力損失が $4f\,\dfrac{L}{D_h}\,\dfrac{\rho u^2}{2}$ と相対 $2\%$ 以内（密度の変化が小さい条件）．
3. **効率の定義**：冷却の効率が $\dfrac{T_{in} - T_{out}}{T_{in} - T_w}$（1 サイクルの，質量流量で重みを付けた平均の温度で）と一致する（相対 $10^{-12}$）．
4. **保存**：インタークーラを含む閉じた系で質量が保存し（相対 $10^{-12}$），気体のエネルギーの増分が，壁からの熱の積算と端の出入りの和に相対 $10^{-9}$ 以内で合う．
