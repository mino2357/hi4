# R-28：インタークーラ

## 要求

インタークーラを，水力直径が小さく，壁温が冷却側の温度に等しい管（束）として置き，吸気の冷却と圧力損失が現れること．中心部は 1 次元の管として解き，入口と出口のタンクは容積として置けること．脈動がどれだけ弱まるかは，計算の結果（予測する量）として，前後の圧力の脈動の振幅を記録すること．冷却の効率を記録すること（`docs/model/eq-intercooler.md` の E-IC01）．

## 受入基準

1. 保存（系の全体で，質量，エネルギー，原子）と，式との一致（`docs/model/README.md` の決まり．式から道具が作る）．
2. `docs/model/checks-engine.md` の R-28 の行（K-114）．
