# R-17：NO の生成（拡大 Zeldovich 機構）

## 要求

既燃部の NO を，化学平衡ではなく，拡大 Zeldovich 機構の反応速度の式（O，O₂，OH，H，N₂ は平衡，N は準定常）で求めること．高温で式が硬くなっても，時間の刻みによらず安定に解けること．NO は，平衡の種から外して，元素の収支とエネルギーに厳密に入れること（残りの種は，NO と CO の量を拘束した平衡．R-13）．排気弁を出た後も，管と容積の中で同じ式を解くこと（R-06）．触媒の入力になる．当量比や点火時期に対する排気の NO の変化は，モデルが予測する量として計算して記録するが，合否の判定には使わないこと（G-03 の C-7）．

## 受入基準

判定値は実装の前の案で，実行して確かめていない．値の根拠は，仕様のテスト項目に書く．

1. **式**：反応による NO の濃度の変化の速さが $\dfrac{2R_1(1 - \alpha^2)}{1 + K\alpha}$（記号は D-23）と一致する（相対 $10^{-12}$）．速度定数が，仕様に書いた式の値と一致する（相対 $10^{-12}$）．
2. **一定の温度と圧力**：温度と圧力を一定にしたとき，NO の濃度の時間変化が，D-23 の積分の表式と相対 $0.1\%$ 以内（$2400\ \text{K}$，$2800\ \text{K}$．$\alpha_0 = 0$ から $\alpha = 0.9$ まで）．
3. **平衡への緩和と安定**：$2800\ \text{K}$ で十分な時間の後，NO の濃度が平衡の値と相対 $0.1\%$ 以内．時間の刻みを $10$ 倍にしても，値が有限で，振動せず，同じ値に収束する．$\alpha_0 > 1$ から始めると，平衡の値へ上から単調に近づく．
4. **収支**：NO の生成と分解があっても，筒内と管を合わせた閉じた系で，N と O の原子の数と全エネルギーが保存する（相対 $10^{-9}$）．温度が $600\ \text{K}$ の管の中では，$1\ \text{s}$ の間の NO の変化が相対 $10^{-6}$ 以下．
