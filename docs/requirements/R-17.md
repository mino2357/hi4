# R-17：NO の生成（拡大 Zeldovich 機構）

## 要求

既燃部の NO を，化学平衡ではなく，拡大 Zeldovich 機構の反応速度の式（O，O₂，OH，H，N₂ は平衡，N は準定常）で求めること（`docs/model/eq-chem.md` の E-R04）．高温で式が硬くなっても，時間の刻みによらず安定に解けること．NO は，平衡の種から外して，元素の収支とエネルギーに厳密に入れること（残りの種は，NO と CO の量を拘束した平衡．R-13）．排気弁を出た後も，管と容積の中で同じ式を解くこと（R-06）．機関から出る NO を見るためのもので，触媒の中の反応は扱わない．当量比や点火時期に対する排気の NO の変化は，モデルが予測する量として計算して記録するが，合否の判定には使わないこと（G-03 の C-7）．

## 受入基準

1. 保存（系の全体で，質量，エネルギー，原子）と，式との一致（`docs/model/README.md` の決まり．式から道具が作る）．
2. `docs/model/checks-cylinder.md` の R-17 の行（K-85，K-86）．
