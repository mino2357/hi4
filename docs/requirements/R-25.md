# R-25：コンプレッサ（特性，流量の式，サージ）

## 要求

コンプレッサを，2 つの容積（入口と出口）の間の要素として置くこと．圧力比と効率は，修正流量と修正回転数の関数（map．式で与える）とすること．コンプレッサを通る流量を状態量に持ち，その運動方程式を解くこと（圧力比から流量を逆算しない）．逆流の側の特性を持ち，サージ（流量と圧力の振動，逆流）を計算できること．出口の全温度と，要する動力を求めること．map の式と寸法は仕様に書き，値と決め方を示すこと（Q-08）．

## 受入基準

判定値は実装の前の案で，実行して確かめていない．値の根拠は，仕様のテスト項目に書く．

1. **修正量**：修正流量と修正回転数が，$\dot m_{corr} = \dot m_c \dfrac{\sqrt{T_{01}/T_{ref}}}{p_{01}/p_{ref}}$，$N_{corr} = \dfrac{N_{tc}}{\sqrt{T_{01}/T_{ref}}}$ と一致する（相対 $10^{-12}$）．
2. **流量の式**：$\dfrac{L_c}{A_c}\dfrac{d\dot m_c}{dt}$ が $p_{01}\,\Pi_c(\dot m_{corr}, N_{corr}) - p_2$ と一致する（相対 $10^{-12}$）．入口と出口の圧力，回転数を一定に保った定常で，$p_2 = p_{01}\Pi_c$（相対 $10^{-9}$）．
3. **map**：圧力比と効率が，仕様に書いた式の値と一致する（相対 $10^{-12}$）．流量と回転数について連続で，逆流の側（$\dot m_c < 0$）まで定義されている．
4. **エネルギー**：出口の容積に入る全 enthalpy の流れと，入口の容積から出る全 enthalpy の流れの差が，動力 $P_c$ に一致する（相対 $10^{-12}$）．等エントロピー効率の定義 $\eta_c = (h_{02s} - h_{01})/(h_{02} - h_{01})$ が成り立つ（相対 $10^{-9}$）．
5. **安定の限界**：コンプレッサ，出口の容積，絞りだけの系で，定常の作動点のまわりに線形化した式の固有値から求めた安定・不安定が，小さい擾乱を与えた計算の振る舞い（減衰か成長か）と一致する．成長率または減衰率が，固有値の実部と相対 $5\%$ 以内．振動の角振動数が，固有値の虚部と相対 $2\%$ 以内．
6. **逆流**：サージで流量が負になっても，状態が有限のまま進み，入口と出口の容積の質量とエネルギーの収支が相対 $10^{-9}$ 以内で合う．
