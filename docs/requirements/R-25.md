# R-25：コンプレッサ（特性，流量の式，サージ）

## 要求

コンプレッサを，入口と出口の 2 つの容積の間の要素として置き，`docs/model/eq-compressor.md` の式（E-C01〜E-C11）で計算すること．流量は状態量として運動方程式で進め，圧力比から逆算しないこと．map は逆流の側まで定義し，サージ（流量と圧力の振動，逆流）を計算できること．map は，揚程係数と流量係数の関係（E-C11．Moore と Greitzer の 3 次式）で与え，翼車がする仕事は Euler の式（E-C07）で与えること．効率は置かずに，そこから導くこと（E-C04）．翼車の径，曲線の形の定数，slip factor は，利用者が変えられる設定とし，既定の値は仕様に書いて，決め方を示すこと（Q-08）．

## 受入基準

1. 式との一致と，釣り合いの保存（`docs/model/README.md` の決まり．式から道具が作る）．
2. `docs/model/checks-turbo.md` の R-25 の行（K-01〜K-05）．
