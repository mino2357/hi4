# R-11：シリンダの幾何，弁の開口面積，可変バルブタイミング

## 要求

シリンダの体積を，スライダ・クランク機構の式でクランク角から求めること（`docs/model/eq-geometry.md` の E-K01〜E-K06）．吸気弁と排気弁の揚程をカムの曲線で与え，揚程から開口面積を求めること（`docs/model/eq-valve.md` の E-L01，E-L02．流量係数は管端の式に入る）．吸気と排気のカムの位相を，それぞれ設定と表（回転数と負荷）で変えられること．1 気筒の同じ動きの 2 弁は，1 つの面積にまとめてよい．

## 受入基準

1. 保存（系の全体で，質量，エネルギー，原子）と，式との一致（`docs/model/README.md` の決まり．式から道具が作る）．
2. `docs/model/checks-cylinder.md` の R-11 の行（K-60〜K-64）．
