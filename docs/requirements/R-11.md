# R-11：シリンダの幾何，弁の開口面積，可変バルブタイミング

## 要求

シリンダの体積を，スライダ・クランク機構の式でクランク角から求めること．吸気弁と排気弁の揚程をカムの曲線で与え，揚程から有効な開口面積（流量係数を含む）を求めること．吸気と排気のカムの位相を，それぞれ設定と表（回転数と負荷）で変えられること．1 気筒の同じ動きの 2 弁は，1 つの面積にまとめてよい．

## 受入基準

判定値は実装の前の案で，実行して確かめていない．値の根拠は，仕様のテスト項目に書く．

1. **体積**：シリンダの体積が，上死点ですきま容積 $V_c = V_d/(\varepsilon - 1)$，下死点で $V_c + V_d$ になり，途中の角度でスライダ・クランクの式の値と一致する（相対 $10^{-12}$）．$dV/d\theta$ が，体積の数値微分と相対 $10^{-6}$ 以内．
2. **揚程**：弁の揚程が，開き始めと閉じ終わりで $0$，その間は正で，最大の揚程と作用角が設定の値に一致する．揚程の曲線は 2 階微分まで連続．
3. **開口面積**：有効な開口面積が，揚程 $0$ で $0$，揚程について単調に増え，弁の座の面積を超えない．2 弁をまとめた面積が 1 弁の $2$ 倍．
4. **位相**：カムの位相を $\Delta$ だけ変えると，揚程の曲線がクランク角で $\Delta$ だけ平行に移る（形は変わらない．相対 $10^{-12}$）．位相の設定の範囲の両端でも，計算が有限のまま進む．
5. **表**：位相の表を使うとき，位相が，表の格子点では表の値に一致し，格子点の間では連続に変わる．
