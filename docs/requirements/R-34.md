# R-34：排気音と吸気音

## 要求

尾管の出口と吸気口の質量流量の変動から，聞く位置の音圧を求め，音として再生できること（`docs/model/eq-sound.md` の E-SN01〜E-SN03．管端を，自由な空間の点音源とみなす）．聞く位置までの距離を，尾管の出口と吸気口のそれぞれに設定できること．計算は実時間より遅いので，計算した波形を記録してから再生すること：周期定常の 1 サイクルの波形を，実際の長さ（$4\pi/\omega$）で繰り返す．排気音と吸気音を，それぞれ入れたり切ったりできること．音圧レベルを表示すること．音色や大きさが実機と合うかは，合否の判定には使わないこと．

## 受入基準

1. 保存（系の全体で，質量，エネルギー，原子）と，式との一致（`docs/model/README.md` の決まり．式から道具が作る）．
2. `docs/model/checks-extra.md` の R-34 の行（K-130〜K-132）．
