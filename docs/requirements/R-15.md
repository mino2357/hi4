# R-15：直噴（燃料の噴射と気化）と，scavenging の集計

## 要求

燃料を，設定した噴射の始まりのクランク角と噴射率で，液体としてシリンダの中に噴射すること．液体の燃料は時定数で気化し，蒸発潜熱は筒内の気体から奪われること（`docs/model/eq-injection.md` の E-I01〜E-I03）．吸気側の管には燃料を供給しないこと．overlap の間に排気側へ出た未燃の空気と，trapping ratio を，気筒ごと，サイクルごとに集計すること（E-I04，E-I05）．ガス交換の間（燃焼の外）は，筒内を一様（入った気体はすぐに完全に混ざる）とするので，吹き抜けは「混ざってから出た未燃の空気」として現れる（この割り切りを解説に書く）．

1. 保存（系の全体で，質量，エネルギー，原子）と，式との一致（`docs/model/README.md` の決まり．式から道具が作る）．
