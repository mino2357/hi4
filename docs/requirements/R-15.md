# R-15：直噴（燃料の噴射と気化）と，scavenging の集計

## 要求

燃料を，設定した噴射の始まりのクランク角と噴射率で，液体としてシリンダの中に噴射すること．液体の燃料は時定数で気化し，蒸発潜熱は筒内の気体から奪われること．吸気側の管には燃料を供給しないこと．overlap の間に排気側へ出た未燃の空気（scavenging）を，気筒ごと，サイクルごとに集計すること．ガス交換の間（燃焼の外）は，筒内を一様（入った気体はすぐに完全に混ざる）とするので，吹き抜けは「混ざってから出た未燃の空気」として現れる（この割り切りを解説に書く）．

## 受入基準

判定値は実装の前の案で，実行して確かめていない．値の根拠は，仕様のテスト項目に書く．

1. **燃料の収支**：1 サイクルに噴射した質量が，気化した質量と，液体のまま残った質量の増分の和に，相対 $10^{-12}$ 以内で合う．
2. **気化による冷却**：弁を閉じた断熱の筒内で，質量 $m_{f}$ の液体の燃料が全部気化したとき，気体の温度の変化が，エネルギーの式（気化の前後で，気体と燃料を合わせた内部エネルギーが，液体の燃料の持ち込む enthalpy の分だけ変わる）から求めた値と相対 $0.1\%$ 以内．
3. **噴射の時期**：噴射の始まりと終わりのクランク角が設定の値に一致し（$10^{-8}\ \text{rad}$），噴射率は，クランク軸が逆に回る段でも $0$ 以上．
4. **吸気側の燃料**：筒内から吸気側への吹き返しが無い運転では，吸気側の管と容積の燃料の蒸気の質量が $0$ のまま．
5. **空気の収支**：1 サイクルに吸気弁から入った未燃の空気の質量が，筒内に残った分，排気弁から出た分，吸気側へ戻った分，燃えた分の和に，相対 $10^{-9}$ 以内で合う．排気弁から出た未燃の空気の質量と，trapping ratio（筒内に残った空気／吸気弁から入った空気）が，気筒ごと，サイクルごとに記録される．
6. **排気の当量比**：周期定常で，1 サイクルに排気弁を出た気体の全体の当量比（燃料に由来する質量 × 量論空燃比 ÷ 空気に由来する質量）が，筒内の燃焼の当量比に trapping ratio を掛けた値と相対 $10^{-6}$ 以内（吸気側への吹き返しの持ち越しが周期的なとき）．
