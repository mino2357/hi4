# R-06：組成と熱物性（新気と既燃ガスの境目）

## 要求

管の中の気体を，空気，燃料の蒸気，既燃ガスのうち空気に由来する質量，既燃ガスのうち燃料に由来する質量の 4 成分と，CO と NO の質量分率，酸素の過不足（触媒の酸素の吸蔵で気体から出入りした酸素の質量．R-33）で表し，流れとともに運ぶこと（`docs/model/eq-pipe.md` の E-P04，E-P08）．内部エネルギーは，生成 enthalpy を含む絶対値で，温度によって比熱が変わること（`docs/model/eq-thermo.md` の E-H01〜E-H07）．物性の値は `ice_2026` の REQ-29 と同じにすること．温度と組成の境目が，圧力と流速を乱さずに運ばれること．管と容積の中でも，CO と NO は反応速度の式（R-13，R-17）に従って変わり，その発熱と吸熱が気体の温度に現れること．反応があっても，原子の数と全エネルギーは保存すること．検証のために，比熱が一定の単一の気体も設定できること．
