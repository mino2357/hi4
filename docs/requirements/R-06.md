# R-06：組成と熱物性（新気と既燃ガスの境目）

## 要求

管の中の気体を，空気，燃料の蒸気，既燃ガスのうち空気に由来する質量，既燃ガスのうち燃料に由来する質量の 4 成分と，CO と NO の質量分率で表し，流れとともに運ぶこと．内部エネルギーは，生成 enthalpy を含む絶対値で，温度によって比熱が変わること．物性の値は `ice_2026` の REQ-29 と同じにすること．温度と組成の境目が，圧力と流速を乱さずに運ばれること．管と容積の中でも，CO と NO は反応速度の式（R-13，R-17）に従って変わり，その発熱と吸熱が気体の温度に現れること（排気管の中の酸化）．反応があっても，原子の数と全エネルギーは保存すること．検証のために，比熱が一定の単一の気体も設定できること．

## 受入基準

判定値は実装の前の案で，実行して確かめていない．値の根拠は，仕様のテスト項目に書く．

1. **値**：空気の気体定数 $288.19\ \text{J/(kg·K)}$，燃料の蒸気の気体定数 $75.586\ \text{J/(kg·K)}$，量論空燃比 $14.503$（相対 $10^{-4}$．`ice_2026` の REQ-29 の受入基準 1 と同じ値）．
2. **温度の逆算**：$200$〜$3000\ \text{K}$ の温度 $T$ と任意の組成から内部エネルギーを求め，それから逆算した温度 $T'$ が $\lvert T' - T\rvert \le 10^{-9}\,T$．
3. **成分の範囲と保存**：どのセルでも，どの時刻でも，$0 \le Y_k \le 1$，$\lvert \sum_k Y_k - 1\rvert \le 10^{-12}$．両端を閉じた管で，各成分の質量が保存する（相対 $10^{-12}$）．
4. **境目の移動**：新気（$350\ \text{K}$）と既燃ガス（$1000\ \text{K}$）が同じ圧力，同じ流速（$50\ \text{m/s}$）で接する境目を，管の長さの半分だけ運んだとき，圧力と流速の乱れが，それぞれ初期の圧力の $0.1\%$，初期の流速の $0.1\%$ 以下．境目の幅（既燃ガスの割合の $10\%$ から $90\%$ まで）が $6$ セル以下（Q-10）．
5. **原子の保存**：当量比の違う既燃ガスが管の中で混ざっても，空気に由来する質量の合計と，燃料に由来する質量の合計が，それぞれ保存する（相対 $10^{-12}$）．
6. **音速**：音速が $\sqrt{\gamma R T}$（$\gamma$，$R$ はその場所の組成と温度の値）と一致し（相対 $10^{-12}$），空気，既燃ガスのそれぞれの中で，小振幅のパルスが距離 $L$ を進む時間が $L/a$ と相対 $0.5\%$ 以内．
7. **管の中の反応**：両端を閉じた断熱の管で，反応があっても，C，H，O，N の原子の数と全エネルギーが保存する（相対 $10^{-9}$）．$1100\ \text{K}$ で，当量比 $1.1$ の既燃ガスと空気を全体の当量比が $0.9$ になるように混ぜた一様な気体では，CO が時間とともに減り，温度が上がる．温度の上がり方が，組成の変化と，内部エネルギーが一定であることから求めた値と相対 $10^{-6}$ 以内．同じ気体を $600\ \text{K}$ にすると，$1\ \text{s}$ の間の CO と NO の変化が相対 $10^{-6}$ 以下．
