# R-26：タービンとウェイストゲート（瞬時の仕事）

## 要求

タービンを，入口と出口の 2 つの容積の間の準定常の要素として置き，`docs/model/eq-turbine.md` の式（E-T01〜E-T09）で計算すること．流量と仕事を，脈動する入口の状態の瞬時値から毎時刻求め，1 サイクルの中の変化と，map の上の作動点の軌跡を記録すること．ウェイストゲートを，同じ 2 つの容積の間の，面積を変えられるオリフィス（`docs/model/eq-wastegate.md` の E-G01）として置くこと．流量と効率の式は仕様に書くこと（Q-08）．
