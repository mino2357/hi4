# R-09：触媒の担体と消音器（流れの抵抗と膨張室）

## 要求

触媒の担体を，開口率を掛けた断面積と，セルの水力直径を持つ管として置き，その圧力損失が現れること（摩擦係数は `docs/model/eq-wall.md` の E-F02 で，層流の $f\,Re$ を正方形のセルの値 $14.2$ にする．反応と暖機はこの要件に含まない）．消音器を，膨張室（断面積の大きい管，または容積）と管の組み合わせとして置き，脈動を弱めること．

## 受入基準

1. 保存（系の全体で，質量，エネルギー，原子）と，式との一致（`docs/model/README.md` の決まり．式から道具が作る）．
2. `docs/model/checks-volume.md` の R-09 の行（K-56，K-57）．
