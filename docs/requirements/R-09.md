# R-09：触媒の担体と消音器（流れの抵抗と膨張室）

## 要求

触媒の担体を，開口率を掛けた断面積と，セルの水力直径を持つ管として置き，その圧力損失が現れること（反応と暖機はこの要件に含まない）．消音器を，膨張室（断面積の大きい管，または容積）と管の組み合わせとして置き，脈動を弱めること．

## 受入基準

判定値は実装の前の案で，実行して確かめていない．値の根拠は，仕様のテスト項目に書く．

1. **担体の摩擦係数**：担体の中の層流の摩擦係数が $f = 14.2/Re$（正方形のセル）に一致する（相対 $10^{-12}$）．
2. **担体の圧力損失**：担体の中の定常の流れ（Mach 数 $0.05$ 以下）の圧力損失が $\Delta p = 4 f\,\dfrac{L}{D_h}\,\dfrac{\rho u^2}{2}$（$D_h$ はセルの水力直径，$u$ は担体の中の流速）と相対 $2\%$ 以内．
3. **開口率**：担体の中の流速が，前後の管の流速に（前後の管の断面積）／（担体の正面の面積 × 開口率）を掛けた値と，定常で相対 $1\%$ 以内（密度の変化が無視できる条件）．
4. **膨張室の透過損失**：断面積の比 $m$，長さ $L_c$ の膨張室（断面積の大きい管）に小振幅の正弦波を入れたとき，透過損失が $10\log_{10}\!\left[1 + \dfrac14\left(m - \dfrac1m\right)^2 \sin^2(k L_c)\right]\ \text{dB}$（$k = \omega/a$）と $\pm 1\ \text{dB}$ 以内（$kL_c = \pi/4$，$\pi/2$，$\pi$）．
5. **保存**：担体と膨張室を含む閉じた系で，質量，全エネルギー，各成分の質量が保存する（相対 $10^{-12}$）．
