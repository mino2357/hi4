# R-04：壁面摩擦

## 要求

管の壁面の摩擦を，Reynolds 数で決まる摩擦係数で扱い，流量に応じた圧力損失と，波の減衰が現れること．管ごとに摩擦係数の倍率を設定できること．検証のために，摩擦係数を一定の値に設定できること．

## 受入基準

判定値は実装の前の案で，実行して確かめていない．値の根拠は，仕様のテスト項目に書く．

1. **式との一致**：摩擦係数が，層流（$Re < 2300$）で $16/Re$，乱流で $0.0791\,Re^{-1/4}$ に，設定した倍率を掛けた値と一致する（相対 $10^{-12}$）．
2. **Fanno の流れ**：一定の断面積，断熱，摩擦係数が一定の管の定常の流れ（入口の Mach 数 $0.3$）で，出口の Mach 数と，入口と出口の全圧の比が，Fanno の流れの式の値と相対 $1\%$ 以内．
3. **向き**：摩擦の力は，流れの向きによらず流れを妨げる向きで，$u = 0$ のとき $0$．
4. **エネルギー**：両端を閉じた断熱の管では，摩擦があっても全エネルギーが保存し（相対 $10^{-12}$），運動エネルギーの合計は，波が往復する時間の平均で減っていく．
