# R-18：4 気筒の配列，点火の順序，気筒ごとの指標

## 要求

シリンダを 4 本並べ，点火の順序（既定は 1–3–4–2）に合わせてクランク角をずらすこと．吸気側はサージタンクと気筒ごとのランナ，排気側は気筒ごとの枝管と合流部でつなぐこと．管の寸法は気筒ごとに設定できること．気筒ごと，サイクルごとに，体積効率，吸気弁が閉じた時点の既燃ガスの割合，IMEP を記録すること．周期定常になったかを判定すること．

## 受入基準

判定値は実装の前の案で，実行して確かめていない．値の根拠は，仕様のテスト項目に書く．

1. **位相**：気筒 $n$ のクランク角が $\theta_n = \theta - \Delta_n$，$(\Delta_1, \Delta_2, \Delta_3, \Delta_4) = (0, 540, 180, 360)^\circ$CA に一致する（既定の順序．相対 $10^{-12}$）．
2. **対称な配管での一致**：4 気筒のランナ，枝管，弁の設定が同じで，サージタンクと合流部へのつながり方が気筒について対称なとき，周期定常で，気筒 $n$ の筒内圧と弁の流量の波形が，気筒 1 の波形を $\Delta_n$ ずらしたものと相対 $10^{-6}$ 以内で一致する．
3. **体積効率の定義**：体積効率が，吸気弁が閉じた時点に筒内に残った未燃の空気の質量を $\rho_{ref} V_d$ で割った値と一致する（相対 $10^{-12}$）．$\rho_{ref}$ を大気の密度にした値と，サージタンクの 1 サイクルの平均の密度にした値の両方を記録する．
4. **系の全体の収支**：周期定常の 1 サイクルで，系の全体（大気への端から端まで）に入った質量と出た質量の差が，入った質量の $10^{-6}$ 以下．C，H，O，N の原子の数についても同じ．
5. **周期定常の判定**：連続する 2 サイクルの，気筒ごとの IMEP と体積効率の差が，設定した値（既定は相対 $10^{-4}$）以下になったサイクルを，周期定常の始まりとして記録する．作った系列に対して，判定がこの定義どおりになる．
6. **格子の収束**：全負荷・$3000\ \text{rpm}$ で，すべての管の $\Delta x$ を半分にしたとき，気筒ごとの体積効率と IMEP の変化が相対 $1\%$ 以下．
