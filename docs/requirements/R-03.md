# R-03：管端（閉端，開放端，絞りを介した容器）

## 要求

管の端を，よどみ状態を与えた容器（大気を含む）に，絞りを介してつなげること（`docs/model/eq-pipeend.md` の E-E01〜E-E08 と，`docs/model/eq-orifice.md` の E-O01，E-O02）．開口の比が $0$（閉端）から $1$（開放端）まで，流れの向き（流入，流出）とチョークを含めて扱えること．開口の比を時間とともに変えられること（弁）．この段階の容器は，状態を固定したもの．

## 受入基準

1. 式との一致と，釣り合いの保存（`docs/model/README.md` の決まり．式から道具が作る）．
2. `docs/model/checks-pipe.md` の R-03 の行（K-31〜K-35）．
