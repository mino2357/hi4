# R-03：管端（閉端，開放端，絞りを介した容器）

## 要求

管の端を，よどみ状態を与えた容器（大気を含む）に，有効な面積 $A_t$ の絞りを介してつなげること．$\psi = A_t/A_p$（$A_p$ は管の断面積）が $0$（閉端）から $1$（開放端）まで，流れの向き（流入，流出）とチョークを含めて扱えること．$\psi$ を時間とともに変えられること（弁）．この段階の容器は，状態を固定したもの（状態が変わる容積は後の段階）．

## 受入基準

判定値は実装の前の案で，実行して確かめていない．値の根拠は，仕様のテスト項目に書く．

1. **閉端の反射**：小振幅（$0.1\%$）のパルスが閉端で反射した後の振幅が，入射の振幅の $+1$ 倍（$\pm 1\%$）．
2. **開放端の反射**：同じパルスが，大気に開いた端（$\psi = 1$）で反射した後の振幅が，入射の振幅の $-1$ 倍（$\pm 2\%$）．
3. **共鳴**：両端を閉じた管の最低次の振動の周期が $2L/a$（相対 $0.5\%$）．一端を閉じ，他端を大気に開いた管では $4L/a$（相対 $1\%$）．
4. **定常の流量**：容器から絞りを通って管へ流れ込む定常の流れと，管から絞りを通って容器へ流れ出る定常の流れのそれぞれで，質量流量が圧縮性のオリフィスの式（D-08）の値と相対 $0.5\%$ 以内．圧力比 $0.9$，$0.7$（亜音速），$0.3$（チョーク）．
5. **極限**：$\psi = 10^{-6}$ の結果が閉端の結果と，$\psi = 1$ の亜音速の流出で管端の圧力が容器の圧力と，それぞれ相対 $10^{-4}$ 以内で合う．
6. **部分的に開いた端**：同じ入射のパルスに対して，$\psi$ を $0$ から $1$ へ増やすと，反射した波の振幅の比が $+1$ から $-1$ へ単調に減る．
7. **保存**：端の面を通った質量，全エネルギー，各成分の質量の積算が，管の中の増分と相対 $10^{-12}$ 以内で合う．
8. **解が求まる**：$\psi$ を $0$ から $1$ へ，また $1$ から $0$ へ時間とともに変え，その間に流れの向きが変わり，絞りがチョークする運転で，管端の方程式の解が求まらなかった回数が $0$．
