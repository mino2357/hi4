# R-14：サイクル変動

## 要求

燃焼の始まりと期間に，サイクルごと，気筒ごとのばらつきを与えられること．ばらつきは，種を固定した擬似乱数で作り，同じ設定から同じ結果が得られること．ばらつきの大きさを設定でき，$0$ にもできること．

## 受入基準

判定値は実装の前の案で，実行して確かめていない．値の根拠は，仕様のテスト項目に書く．

1. **大きさ**：燃焼の期間のばらつきの設定を $\sigma$ としたとき，$1000$ サイクルの燃焼の期間の標準偏差が $\sigma$ と相対 $10\%$ 以内．
2. **$0$ の設定**：ばらつきを $0$ にすると，周期定常でどのサイクルも同じ結果になる（IMEP の差が相対 $10^{-9}$ 以下）．
3. **再現**：同じ種から始めた 2 回の計算の結果が，同じ処理系ではビット単位で同じ．
4. **独立**：気筒ごとのばらつきは互いに独立（4 気筒の $1000$ サイクルで，気筒の間の相関係数の絶対値が $0.1$ 以下）．
5. **平均**：ばらつきを入れても，燃焼の期間の $1000$ サイクルの平均が，ばらつき $0$ のときの値と相対 $1\%$ 以内．
