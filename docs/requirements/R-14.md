# R-14：サイクル変動（前のサイクルとの決定論的な結合）

## 要求

サイクル変動を，乱数を使わずに，前のサイクルとの決定論的な結合だけから現れるものとして扱うこと．結合の経路は，筒内に残る既燃ガスの量と温度，燃え残った燃料の持ち越し，管の中の圧力波の状態の 3 つ．そのために，燃焼の期間と，燃える割合（部分燃焼と失火を含む）を，筒内の状態の関数として与えること（`docs/model/eq-combustion.md` の E-X02，E-X03．式は仕様．Q-14）．サイクルごと，気筒ごとの系列（IMEP，吸気弁が閉じた時点の既燃ガスの割合，燃えた割合）を記録し，周期定常か，周期が 2 サイクルか，それ以外かを分類して示すこと．安定か不安定かは，モデルが予測する量として記録し，合否の判定には使わないこと．点火栓の近くの流れの揺らぎによる変動は扱わない（この割り切りを解説に書く）．
