# R-14：サイクル変動（前のサイクルとの決定論的な結合）

## 要求

サイクル変動を，乱数を使わずに，前のサイクルとの決定論的な結合だけから現れるものとして扱うこと．結合の経路は，筒内に残る既燃ガスの量と温度，燃え残った燃料の持ち越し，管の中の圧力波の状態の 3 つ．そのために，燃焼の期間と，燃える割合（部分燃焼と失火を含む）を，吸気弁が閉じた時点の既燃ガスの割合 $x_{b,IVC}$，当量比，未燃部の温度，筒内の密度，回転数の関数として与えること（式は仕様．Q-14）．サイクルごと，気筒ごとの系列（IMEP，$x_{b,IVC}$，燃えた割合）を記録し，周期定常か，周期が 2 サイクルか，それ以外かを分類して示すこと．安定か不安定かは，モデルが予測する量として記録し，合否の判定には使わないこと．点火栓の近くの流れの揺らぎによる変動は扱わない（0 次元では乱数なしに表せないため．この割り切りを解説に書く）．

## 受入基準

判定値は実装の前の案で，実行して確かめていない．値の根拠は，仕様のテスト項目に書く．

1. **乱数を使わない**：計算のコードに乱数の呼び出しが無い（静的に調べる）．同じ設定から始めた 2 回の計算の結果が，同じ処理系ではビット単位で同じ．
2. **式との一致**：燃焼の期間と燃える割合が，仕様に書いた式の値と一致する（相対 $10^{-12}$）．燃える割合は $0$ 以上 $1$ 以下．
3. **持ち越しの収支**：燃え残った燃料と空気は，筒内に残るか，排気へ出る．サイクルをまたいだ 100 サイクルの通算で，筒内と管を合わせた系の，空気に由来する質量と燃料に由来する質量の収支が，それぞれ相対 $10^{-9}$ 以内で合う．
4. **失火**：燃える割合が $0$ のサイクルでも，状態が有限のまま進み，3 の収支が合う．
5. **結合を切った極限**：燃焼の式に与える $x_{b,IVC}$，当量比，未燃部の温度を固定の値にし，燃える割合を $1$ にすると，回転数を一定にした運転で周期定常になり，連続する 2 サイクルの IMEP の差が相対 $10^{-9}$ 以下．
6. **分類の定義**：連続する $N$ サイクルの IMEP の系列 $w_n$ について，$\max_n \lvert w_{n+1} - w_n\rvert \le \varepsilon\,\bar w$ なら「周期定常」，そうでなく $\max_n \lvert w_{n+2} - w_n\rvert \le \varepsilon\,\bar w$ なら「周期 2」，どちらでもなければ「それ以外」と分類する（$\bar w$ は平均．$N$ と $\varepsilon$ は仕様）．作った系列（一定，交互，不規則）に対して，分類がこの定義どおりになる．
