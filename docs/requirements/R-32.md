# R-32：触媒の暖機と熱容量

## 要求

触媒の担体の温度を，担体の熱容量，気体との熱のやりとり，軸方向の熱伝導，外への放熱から求めること（`docs/model/eq-wall.md` の E-U02．壁温の切替の「触媒の担体」．気体との熱は管の壁の式をそのまま使う）．担体の温度は，担体に沿った分布を持つこと（セルごと）．冷えた状態からの暖機（温度の前線が下流へ進むこと）が現れること．暖機に要る時間は，モデルが予測する量として記録し，合否の判定には使わないこと．

## 受入基準

1. 保存（系の全体で，質量，エネルギー，原子．担体の熱と，吸蔵した酸素を含む）と，式との一致（`docs/model/README.md` の決まり．式から道具が作る）．
2. `docs/model/checks-catalyst.md` の R-32 の行（K-120，K-121）．
