# R-27：過給機の軸，過給圧の制御，過渡の応答

## 要求

過給機の軸の回転を，タービンの仕事率とコンプレッサの動力の釣り合いの式で進めること．過給圧（サージタンクの圧力の 1 サイクルの平均）が目標になるように，ウェイストゲートの面積を制御すること．定常の運転点を求めるときに，軸の慣性を小さくして収束を早めてよいが，結果は，本来の慣性に戻して周期定常になったものを採ること．スロットルを階段状に開く過渡を，回転数が自由な運転と本来の慣性で計算し，過給圧，過給機の回転数，軸トルクの時間変化を記録すること（立ち上がりの時間は予測する量で，合否の判定には使わない）．

## 受入基準

判定値は実装の前の案で，実行して確かめていない．値の根拠は，仕様のテスト項目に書く．

1. **軸の式**：$I_{tc}\,\omega_{tc}\,\dfrac{d\omega_{tc}}{dt}$ が $\eta_m P_t - P_c$ と一致する（相対 $10^{-12}$）．軸の運動エネルギーの増分が，$\int (\eta_m P_t - P_c)\,dt$ と相対 $10^{-9}$ 以内で合う．
2. **周期定常の釣り合い**：周期定常の 1 サイクルで，$\eta_m \oint P_t\,dt$ と $\oint P_c\,dt$ の差が，$\oint P_c\,dt$ の $10^{-6}$ 以下（連続する 2 サイクルの過給機の回転数の差が，周期定常の判定の値以下のとき）．
3. **本来の慣性**：定常の運転点の結果として記録される値が，本来の慣性で計算した最後の周期定常のサイクルの値である（慣性を小さくした区間の値が混ざらない）．
4. **過給圧の制御（届く点）**：ウェイストゲートを全部閉じたときの過給圧が目標を超える運転点では，制御の収束の後，過給圧が目標 $\pm 0.5\ \text{kPa}$ に入る．
5. **過給圧の制御（届かない点）**：ウェイストゲートを全部閉じても過給圧が目標に届かない運転点では，ウェイストゲートの面積が $0$ のまま．
6. **過渡の収支**：過渡の計算で，系の全体の質量の収支，クランク軸と過給機の軸のエネルギーの収支が，それぞれ相対 $10^{-9}$ 以内で合う．
