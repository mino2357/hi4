# R-27：過給機の軸，定常点の求め方（簡易計算を出発点にする），過給圧の制御，過渡の応答

## 要求

過給機の軸を `docs/model/eq-shaft.md`（E-S01）で進め，過給圧を `docs/model/eq-boost.md`（E-B01，E-B02）で制御すること．定常の運転点は 2 段で求めること：(1) `docs/model/eq-simple.md` の簡易計算（E-M01〜E-M03．map と機関側の 1 サイクルの平均の量から，平均値の代数の式として解く．脈動は使わない）．(2) その解を出発点にして，1 次元の計算を，本来の軸の慣性と制御器で，周期定常まで進める．周期定常に達しない運転点は，周期定常／周期 2／それ以外に分類して記録すること（R-14 と同じ定義）．簡易計算の解と，周期定常の解の差を記録すること（予測する量）．遅い変数の方程式を直接解いて収束を早める案は入れない（Q-15）．スロットルを階段状に開く過渡を，回転数が自由な運転と本来の慣性で計算し，過給圧，過給機の回転数，軸トルクの時間変化を記録すること（立ち上がりの時間は予測する量）．

## 受入基準

1. 式との一致と，釣り合いの保存（`docs/model/README.md` の決まり．式から道具が作る）．
2. `docs/model/checks-turbo.md` の R-27 の行（K-10〜K-15）．
