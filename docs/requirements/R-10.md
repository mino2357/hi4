# R-10：管の壁の温度の変化

## 要求

管ごとに，壁の熱容量を持たせて，壁温が気体からの熱と外への放熱によって変わるようにできること（`docs/model/eq-wall.md` の E-U01．排気マニホールドの暖機）．壁温は管に沿った分布を持つこと（セルごと）．壁温を設定値に固定することも選べること（E-U00）．
