# R-10：管の壁の温度の変化

## 要求

管ごとに，壁の熱容量を持たせて，壁温が気体からの熱と外への放熱によって変わるようにできること（排気マニホールドの暖機）．壁温は管に沿った分布を持つこと（セルごと）．壁温を設定値に固定することも選べること．

## 受入基準

判定値は実装の前の案で，実行して確かめていない．値の根拠は，仕様のテスト項目に書く．

1. **壁の収支**：セルごとの壁のエネルギーの増分 $C_w\,\Delta T_w$ が，気体から壁への熱の積算と，外への放熱 $h_e A_e (T_w - T_{amb})$ の積算の差に，相対 $10^{-9}$ 以内で合う（$C_w$ は壁の熱容量，$h_e$，$A_e$ は外側の熱伝達率と面積，$T_{amb}$ は周りの温度）．
2. **釣り合いの壁温**：気体の状態を一定に保ったとき，壁温が $T_w = \dfrac{h_c A_i T + h_e A_e T_{amb}}{h_c A_i + h_e A_e}$ に収束する（$A_i$ は内側の面積．相対 $0.5\%$）．
3. **時定数**：そのときの壁温の変化の時定数が $\dfrac{C_w}{h_c A_i + h_e A_e}$ と相対 $2\%$ 以内．
4. **全体の収支**：気体，壁，外への放熱を合わせたエネルギーの収支が，相対 $10^{-9}$ 以内で合う．
5. **固定**：壁温の固定を選ぶと，R-05 だけのときと同じ結果になる（同じ処理系でビット単位）．
