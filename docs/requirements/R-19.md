# R-19：回転系と動力計

## 要求

クランク軸の回転を，4 気筒のガス圧によるトルク，往復質量の慣性によるトルク，摩擦，動力計のトルクの運動方程式で進めること（`docs/model/eq-rotation.md` の E-D01〜E-D07）．回転数を一定に保つ運転と，回転数が自由な運転（始動，アイドル，過渡）を選べること．動力計は，回転数を保つ制御と，トルクを与える制御を選べること．摩擦の式は仕様に書き，値と決め方を示すこと．逆に回る段でも，燃焼と噴射が逆向きに進まないこと．

## 受入基準

1. 保存（系の全体で，質量，エネルギー，原子）と，式との一致（`docs/model/README.md` の決まり．式から道具が作る）．
2. `docs/model/checks-engine.md` の R-19 の行（K-95〜K-99）．
