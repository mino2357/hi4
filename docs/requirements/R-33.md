# R-33：三元触媒の反応と，酸素の吸蔵

## 要求

触媒の表面での反応（CO の酸化，未燃の燃料の酸化，CO による NO の還元）と，酸素の吸蔵と放出を扱うこと（`docs/model/eq-catalyst.md` の E-CA02〜E-CA07，E-CA09，E-CA10．担体へ入る熱は `docs/model/eq-wall.md` の E-U02）．反応の速さは，表面の濃度と担体の温度から決め，気体と表面の間の物質移動を扱うこと．反応の発熱は，別に加える項ではなく，気体と表面の間を移る成分の全 enthalpy（生成 enthalpy を含む）の差として，担体に入ること．酸素の吸蔵のために，気体の成分に「酸素の過不足」を加えること（R-06）．CO，未燃の燃料，NO の浄化率を記録すること．反応の速さの式と定数は仕様に書き，値と決め方を示すこと（G-03 の C-7）．浄化率の当量比や温度への依存，light-off の温度は，モデルが予測する量として記録し，合否の判定には使わないこと．機関から出る未燃の燃料は，燃え残り（部分燃焼と失火）によるものだけで，すきまや油膜によるものは扱わない（P-65．この割り切りを解説に書く）．反応を切る設定を選べること．

## 受入基準

1. 保存（系の全体で，質量，エネルギー，原子．担体の熱と，吸蔵した酸素を含む）と，式との一致（`docs/model/README.md` の決まり．式から道具が作る）．
2. `docs/model/checks-catalyst.md` の R-33 の行（K-122〜K-126）．
