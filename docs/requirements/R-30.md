# R-30：スロットルを急に閉じたときの過渡と，再循環弁

## 要求

スロットルを設定した時間で閉じる過渡を計算し，スロットルの上流の管の圧力波，コンプレッサの作動点の動き（サージに入るか）を記録すること．コンプレッサの出口側から入口側へ気体を戻す再循環弁（オリフィス）を置けること（`docs/model/eq-misc.md` の E-TH01〜E-TH03）．弁を開く条件は仕様に書くこと．過渡の波形は予測する量で，合否の判定には使わないこと．

## 受入基準

1. 保存（系の全体で，質量，エネルギー，原子）と，式との一致（`docs/model/README.md` の決まり．式から道具が作る）．
2. `docs/model/checks-engine.md` の R-30 の行（K-115，K-116）．
