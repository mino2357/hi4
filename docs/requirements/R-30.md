# R-30：スロットルを急に閉じたときの過渡と，再循環弁

## 要求

スロットルを設定した時間で閉じる過渡を計算し，スロットルの上流の管の圧力波，コンプレッサの作動点の動き（サージに入るか）を記録すること．コンプレッサの出口側から入口側へ気体を戻す再循環弁（オリフィス）を置けること．弁を開く条件（スロットルの前後の圧力差，または指令）は仕様に書くこと．過渡の波形は予測する量で，合否の判定には使わないこと．

## 受入基準

判定値は実装の前の案で，実行して確かめていない．値の根拠は，仕様のテスト項目に書く．

1. **スロットルの動き**：スロットルの開度が，設定した時間と形（仕様に書いた式）どおりに変わる（相対 $10^{-12}$）．
2. **再循環弁の流量**：弁を通る流量が，圧縮性のオリフィスの式（D-08）の値と一致する（相対 $10^{-9}$）．閉じているとき流量が $0$．
3. **開く条件**：弁の開閉が，仕様に書いた条件の式どおりに切り替わる（作った圧力の系列に対して）．
4. **収支**：過渡の間，系の全体の質量の収支が相対 $10^{-9}$ 以内で合う．状態が有限のまま進む．
