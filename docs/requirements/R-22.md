# R-22：外部 EGR

## 要求

排気側の任意の容積から吸気側の任意の容積へ，管，弁，冷却器（壁温が一定で熱伝達の大きい管）で気体を戻せること．EGR 率を定義して，記録すること（`docs/model/eq-egr.md` の E-EG01）．

## 受入基準

1. 保存（系の全体で，質量，エネルギー，原子）と，式との一致（`docs/model/README.md` の決まり．式から道具が作る）．
2. `docs/model/checks-engine.md` の R-22 の行（K-106）．
