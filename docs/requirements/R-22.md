# R-22：外部 EGR

## 要求

排気側の任意の容積から吸気側の任意の容積へ，管，弁，冷却器（壁温が一定で熱伝達の大きい管）で気体を戻せること．EGR 率を定義して，記録すること．

## 受入基準

判定値は実装の前の案で，実行して確かめていない．値の根拠は，仕様のテスト項目に書く．

1. **保存**：EGR の経路を含む系で，R-18 の受入基準 4（系の全体の収支）が成り立つ．
2. **EGR 率の定義**：EGR 率が，1 サイクルに EGR の弁を通った質量を，同じ 1 サイクルに 4 気筒の吸気弁を通って筒内に入った質量の合計で割った値と一致する（相対 $10^{-12}$）．
3. **弁を閉じる**：EGR の弁を閉じると，弁を通る流量が $0$ で，吸気側に既燃ガスが EGR の経路から入らない（EGR の管の吸気側の端の面を通る質量が $0$）．
