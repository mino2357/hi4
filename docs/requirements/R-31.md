# R-31：脈動する流れでのタービンの，準定常からのずれ

## 要求

タービンの入口のケーシング（スクロール）を，断面積が変わる 1 次元の管として解き，翼車だけを準定常の要素とする形を選べること（管の式と，`docs/model/eq-turbine.md` の式を組み合わせる．新しい式は無い）．これにより，スクロールの中の気体の充填と波の伝播による，流量と膨張比の関係の準定常からのずれ（軌跡が輪になること）が現れること．スクロールの長さと断面積の分布を設定できること．準定常の形（R-26）と切り替えて比べられること．ずれの大きさは予測する量で，合否の判定には使わないこと．

## 受入基準

1. 保存（系の全体で，質量，エネルギー，原子）と，式との一致（`docs/model/README.md` の決まり．式から道具が作る）．
2. `docs/model/checks-engine.md` の R-31 の行（K-117，K-118）．
