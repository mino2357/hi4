# R-31：脈動する流れでのタービンの，準定常からのずれ

## 要求

タービンの入口のケーシング（スクロール）を，断面積が変わる 1 次元の管として解き，翼車だけを準定常の要素とする形を選べること．これにより，スクロールの中の気体の充填と波の伝播による，流量と膨張比の関係の準定常からのずれ（軌跡が輪になること）が現れること．スクロールの長さと断面積の分布を設定できること．準定常の形（R-26）と切り替えて比べられること．ずれの大きさは予測する量で，合否の判定には使わないこと．

## 受入基準

判定値は実装の前の案で，実行して確かめていない．値の根拠は，仕様のテスト項目に書く．

1. **定常の一致**：入口の状態が一定のとき，定常の流量と仕事率が，準定常の形（R-26）の値と相対 $10^{-6}$ 以内で一致する（スクロールの摩擦と熱伝達を $0$ にして）．
2. **長さの極限**：入口の圧力を正弦波で変えたとき，スクロールの長さを $1/2$，$1/4$，$1/8$ にしていくと，1 サイクルの仕事と準定常の形の値との差が単調に小さくなり，$1/8$ のときの差が，もとの長さのときの差の $1/4$ 以下．
3. **保存**：スクロールを含む系で，質量が保存し（相対 $10^{-12}$），入口から入った全 enthalpy の積算が，出口へ出た積算と仕事の和に相対 $10^{-9}$ 以内で合う（周期定常の 1 サイクル）．
4. **記録**：瞬時の流量と膨張比の組が，1 サイクルにわたって記録される．
