# R-23：A/F センサ（限界電流式）の出力

## 要求

排気側の設定した位置（タービンの上流か下流かを選べる）に A/F センサを置き，その位置の気体の組成，圧力，温度から出力を求めること（`docs/model/eq-sensor.md` の E-AF01〜E-AF03）．出力は，限界電流式のセンサの仕組みに沿って作ること：拡散層を通って検出室に入る各種の流束から，検出室を量論に保つのに要る酸素のポンプ電流を求める．リッチの側では，H₂ と CO が O₂ と違う拡散係数を持つことによる出力のずれが現れること．圧力による出力の変化を入れること．応答の遅れを，検出室と保護カバーの中の気体の入れ替わりの時定数で表すこと．気体がセンサに届くまでの遅れは，管の中の流れから現れること（別の遅れを足さない）．
