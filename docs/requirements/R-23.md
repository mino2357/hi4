# R-23：A/F センサ（限界電流式）の出力

## 要求

排気側の設定した位置（タービンの上流か下流かを選べる）に A/F センサを置き，その位置の気体の組成，圧力，温度から出力を求めること．出力は，限界電流式のセンサの仕組みに沿って作ること：拡散層を通って検出室に入る各種の流束（その位置のモル分率と，種ごとの拡散係数に比例する）から，検出室を量論に保つのに要る酸素のポンプ電流を求める．リッチの側では，H₂ と CO が O₂ と違う拡散係数を持つことによる出力のずれが現れること．圧力による出力の変化（拡散の圧力への依存）を入れること．センサの応答の遅れを，検出室と保護カバーの中の気体の入れ替わりの時定数で表すこと．気体がセンサに届くまでの遅れは，管の中の流れから現れること（別の遅れを足さない）．出力から換算した当量比（表示と制御に使う値）を求めること．

## 受入基準

判定値は実装の前の案で，実行して確かめていない．値の根拠は，仕様のテスト項目に書く．

1. **ポンプ電流の式**：定常のポンプ電流が，仕様に書いた式（各種のモル分率，拡散係数，圧力，温度の関数）の値と一致する（相対 $10^{-12}$）．
2. **量論の点**：H₂ と CO を含まない気体（CO₂，H₂O，N₂ だけ）では，ポンプ電流が $0$．
3. **希薄の側の換算**：O₂，N₂，CO₂，H₂O だけを含む気体（希薄の完全燃焼の組成）では，出力から換算した当量比が，その気体の当量比（燃料に由来する質量 × 量論空燃比 ÷ 空気に由来する質量）と相対 $10^{-6}$ 以内．
4. **リッチの側のずれ**：H₂ と CO を含む気体での換算した当量比と，その気体の当量比との差が，仕様に書いた式（拡散係数の比から導く）の値と相対 $10^{-6}$ 以内．
5. **応答**：組成を階段状に変えたとき，出力が，時定数 $\tau_s$ の一次遅れの解 $1 - \exp(-t/\tau_s)$ と相対 $0.1\%$ 以内．$\tau_s$ が仕様に書いた式の値と一致する（相対 $10^{-12}$）．
6. **圧力**：組成を変えずに圧力を変えたときの出力の比が，仕様に書いた式の値と相対 $10^{-9}$ 以内．
7. **影響しない**：センサを置いても，流れと機関の計算の結果が変わらない（センサの出力を制御に使わない設定で，同じ処理系でビット単位）．
