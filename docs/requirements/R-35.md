# R-35：損失の内訳と，最適化

## 要求

周期定常の 1 サイクルについて，供給した燃料の発熱量が，軸の仕事，摩擦，筒内の壁への熱，管と容積の壁への熱，気体が持ち出す分にどう分かれるかを求めて示すこと（`docs/model/eq-performance.md` の E-A09〜E-A16）．ポンプ仕事と，タービンの仕事は，別に示すこと．吸気と排気のカムの位相などの設定を，与えた範囲の中で動かして，軸トルクまたは熱効率が最大になる組を探せること（`docs/model/eq-optimize.md` の E-OP01，E-OP02．探し方は仕様に書く）．最適化が比べるのは，周期定常と判定された運転点の値だけとし，判定の値より小さい差には優劣を付けないこと．途中で止めて再開できること．見つかった組と，最大の値は，モデルが予測する量で，合否の判定には使わないこと．
