# R-05：管の壁との熱のやりとり

## 要求

管の中の気体と壁の間の熱のやりとりを，摩擦係数から決まる熱伝達率（Reynolds–Colburn の相似）と，管ごとの壁温（設定値）で扱うこと．管ごとに熱伝達の倍率を設定できること．検証のために，一定の熱流束を与えられること．

## 受入基準

判定値は実装の前の案で，実行して確かめていない．値の根拠は，仕様のテスト項目に書く．

1. **式との一致**：熱伝達率が $h_c = \dfrac{f}{2}\,\rho \lvert u\rvert c_p\,Pr^{-2/3}$ に設定した倍率を掛けた値と一致し，流速が小さいときは層流の Nusselt 数 $3.66$ に当たる値を下回らない（相対 $10^{-12}$）．
2. **向き**：気体の温度が壁温に等しいとき，熱のやりとりは $0$．熱は温度の高い側から低い側へ流れる．
3. **収支**：管の中の全エネルギーの増分が，壁からの熱の積算と，端の面を通った全エネルギーの積算の和に，相対 $10^{-9}$ 以内で合う．
4. **壁温が一定の管の定常の流れ**（Mach 数 $0.1$ 以下）：出口と入口の温度が $\dfrac{T_{out} - T_w}{T_{in} - T_w} = \exp\!\left(-St\,\dfrac{4L}{D}\right)$ を相対 $2\%$ 以内で満たす（$St = h_c/(\rho \lvert u\rvert c_p)$）．
5. **Rayleigh の流れ**：一定の断面積，摩擦なし，一定の熱流束を与えた定常の流れ（比熱一定）で，出口の Mach 数と全温度が，Rayleigh の流れの式の値と相対 $1\%$ 以内．
