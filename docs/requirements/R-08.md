# R-08：合流部と分岐

## 要求

3 本以上の管が集まる合流部と分岐を置けること．既定は，流れの向きと枝管の角度による圧力損失を扱うモデルとすること（pulse converter のように，運動量の向きを使う形を表すため）．容積による合流部（流れ込んだ運動量の向きを失う）も選べること．どちらのモデルでも，質量，エネルギー，成分が保存すること．

## 受入基準

判定値は実装の前の案で，実行して確かめていない．値の根拠は，仕様のテスト項目に書く．

1. **保存**：合流部を含む閉じた系で，どちらのモデルでも，系の全体の質量，全エネルギー，各成分の質量の変化が相対 $10^{-12}$ 以下．
2. **対称**：同じ管を対称につないだ分岐の定常の流れで，分かれた流量の差が相対 $10^{-6}$ 以下．
3. **小振幅の波の反射と透過**：断面積 $A_1$ の管から来た小振幅のパルスが，断面積 $A_2, \dots, A_n$ の管との合流部に当たったとき，反射した波の振幅の比が $\dfrac{A_1 - \sum_{j \ge 2} A_j}{\sum_{j \ge 1} A_j}$，透過した波の振幅の比が $\dfrac{2A_1}{\sum_{j \ge 1} A_j}$ と，それぞれ $\pm 0.03$ 以内（どちらのモデルでも．気体は一様で，平均の流れは無い．容積による合流部の容積は下限の値）．
4. **容積による合流部の損失**：容積による合流部を通る定常の流れ（Mach 数 $0.2$）の全圧の損失が，流れ込む側の動圧の $1$ 倍（$\pm 5\%$）．
5. **向きによる損失**：向きを扱うモデルで，3 本の管の合流部の定常の流れの全圧の損失係数が，仕様に書いたモデルの式の値と相対 $1\%$ 以内．枝管のなす角 $30^\circ$，$90^\circ$，$150^\circ$ と，流量の比 $0.25$，$0.5$，$0.75$ の 9 通り．
