# R-08：合流部と分岐

## 要求

3 本以上の管が集まる合流部と分岐を置けること．既定は容積による合流部（流れ込んだ運動量の向きを失う）とし，流れの向きと枝管の角度による圧力損失を扱うモデルも選べること（pulse converter のように，運動量の向きを使う形を表すため）．どちらのモデルでも，質量，エネルギー，成分が保存すること．

## 受入基準

判定値は実装の前の案で，実行して確かめていない．値の根拠は，仕様のテスト項目に書く．

1. **保存**：合流部を含む閉じた系で，どちらのモデルでも，系の全体の質量，全エネルギー，各成分の質量の変化が相対 $10^{-12}$ 以下．
2. **対称**：同じ管を対称につないだ分岐の定常の流れで，分かれた流量の差が相対 $10^{-6}$ 以下．
3. **小振幅の波の反射と透過**：断面積 $A_1$ の管から来た小振幅のパルスが，断面積 $A_2, \dots, A_n$ の管との合流部に当たったとき，反射した波の振幅の比が $\dfrac{A_1 - \sum_{j \ge 2} A_j}{\sum_{j \ge 1} A_j}$，透過した波の振幅の比が $\dfrac{2A_1}{\sum_{j \ge 1} A_j}$ と，それぞれ $\pm 0.03$ 以内（気体は一様．合流部の容積は下限の値）．
4. **既定のモデルの損失**：容積による合流部を通る定常の流れ（Mach 数 $0.2$）の全圧の損失が，流れ込む側の動圧の $1$ 倍（$\pm 5\%$）．
5. **向きによる損失**：向きを扱うモデルで，T 字の合流部の定常の流れの全圧の損失係数が，仕様に書いたモデルの式の値と相対 $1\%$ 以内．同じ流量で，まっすぐ抜ける向きの損失が，$90^\circ$ 曲がる向きの損失より小さい．
6. **向きによる干渉の違い**：向きを扱うモデルで，1 本の枝管から入れたパルスが，ほかの枝管へ伝わる振幅が，枝管の角度の設定によって変わる（容積による合流部では，どの枝管へも同じ）．
