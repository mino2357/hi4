# R-20：運転点の計算，空燃比と点火時期の制御，性能の指標，性能曲線とマップ

## 要求

回転数と負荷を与えて，周期定常の運転点を計算すること．噴射量は，気筒ごとに，吸気弁が閉じた時点の筒内の空気の質量と目標の当量比から決めること．点火時期は R-16 に従うこと．性能の指標（IMEP，BMEP，軸トルク，軸出力，燃料消費率，体積効率，熱効率，エネルギーの内訳）を求めること．回転数の掃引（性能曲線）と，回転数と負荷のマップを計算し，途中で止めて再開できること．

## 受入基準

判定値は実装の前の案で，実行して確かめていない．値の根拠は，仕様のテスト項目に書く．

1. **指標の定義**：各指標が，仕様に書いた定義式の値と一致する（相対 $10^{-12}$）．$\text{BMEP} = 4\pi T_b/V_{d,total}$（$T_b$ は軸トルクの 1 サイクルの平均，$V_{d,total}$ は行程容積の合計）．
2. **噴射量**：燃料が点火までに全部気化する条件で，点火の時点の筒内の当量比（未燃部の燃料の蒸気 × 量論空燃比 ÷ 未燃の空気）が，目標の値と相対 $10^{-6}$ 以内（気筒ごと）．
3. **エネルギーの内訳**：周期定常の 1 サイクルで，供給した燃料の発熱量が，軸の仕事，摩擦，筒内と管の壁への熱，系から出る気体と入る気体の enthalpy の差（未燃の成分の化学エネルギーを含む）の和に，発熱量の $10^{-4}$ 以内で合う．
4. **独立**：性能曲線とマップの各点の結果が，その点だけを単独で計算した結果と，相対 $10^{-4}$ 以内で合う（計算の順によらない）．
5. **再開**：掃引を途中で止めて再開した結果が，止めずに計算した結果と相対 $10^{-9}$ 以内で合う．
