# R-20：運転点の計算，空燃比と点火時期の制御，性能の指標，性能曲線とマップ

## 要求

回転数と負荷を与えて，周期定常の運転点を計算すること．噴射量は，気筒ごとに，吸気弁が閉じた時点の筒内の空気の質量と目標の当量比から決めること（`docs/model/eq-fuel.md` の E-N03，E-N04）．点火時期は R-16 に従うこと．性能の指標を求めること（`docs/model/eq-performance.md` の E-A01〜E-A08 と，エネルギーの内訳）．回転数の掃引（性能曲線）と，回転数と負荷のマップを計算し，途中で止めて再開できること．

## 受入基準

1. 保存（系の全体で，質量，エネルギー，原子）と，式との一致（`docs/model/README.md` の決まり．式から道具が作る）．
2. `docs/model/checks-engine.md` の R-20 の行（K-100〜K-103）．
