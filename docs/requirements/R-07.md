# R-07：容積（状態が変わる容器）

## 要求

管端をつなぐ容器として，中の気体の質量，エネルギー，組成が出入りによって変わる容積を置けること（`docs/model/eq-volume.md` の E-V01〜E-V10）．容積は流速を持たず，流れ込んだ運動エネルギーは内部エネルギーになること．容積の壁との熱のやりとりを設定できること．時間の刻みに対して小さすぎる容積は，設定の時点で受け付けず，知らせること．

## 受入基準

1. 保存（系の全体で，質量，エネルギー，原子）と，式との一致（`docs/model/README.md` の決まり．式から道具が作る）．
2. `docs/model/checks-volume.md` の R-07 の行（K-50〜K-52）．
