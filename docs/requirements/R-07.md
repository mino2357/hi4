# R-07：容積（状態が変わる容器）

## 要求

管端をつなぐ容器として，中の気体の質量，エネルギー，組成が出入りによって変わる容積を置けること（サージタンク，合流部，消音器の室など）．容積は流速を持たず，流れ込んだ運動エネルギーは内部エネルギーになること．容積の壁との熱のやりとりを設定できること．時間の刻みに対して小さすぎる容積は，設定の時点で受け付けず，知らせること．

## 受入基準

判定値は実装の前の案で，実行して確かめていない．値の根拠は，仕様のテスト項目に書く．

1. **保存**：管と容積だけでできた閉じた系で，系の全体の質量，全エネルギー，各成分の質量の変化が，$10^4$ ステップで相対 $10^{-12}$ 以下（壁との熱は $0$）．
2. **断熱の充填**（比熱一定）：圧力 $p_0$，温度 $T_0$ に固定した容器から，絞りと短い管を通して，初めの圧力 $p_i$，温度 $T_i$ の容積へ，圧力が $p_0$ に等しくなるまで流し込んだとき，容積の終わりの温度が $T_f = \dfrac{p_0}{p_i/T_i + (p_0 - p_i)/(\gamma T_0)}$ と相対 $0.5\%$ 以内（第一法則 $m_f c_v T_f = m_i c_v T_i + (m_f - m_i)\,c_p T_0$ から）．
3. **Helmholtz 共鳴**：一端を大気に開いた管（長さ $L$，断面積 $A$）の他端に容積 $V$ をつないだ系の最低次の振動の角振動数が，$kL\,\tan(kL) = AL/V$ の最小の正の根 $k$ から決まる $\omega = k a$ と相対 $1\%$ 以内．
4. **壁との熱**：容積の壁からの熱が $h_c A_w (T_w - T)$ と一致し（相対 $10^{-12}$），容積のエネルギーの増分が，出入りの全 enthalpy の積算と壁からの熱の積算の和に相対 $10^{-9}$ 以内で合う．
5. **小さすぎる容積**：容積が，つながる管の端のセルの体積の和より小さい設定は受け付けられず，その容積の名前と下限の値が知らされる．
