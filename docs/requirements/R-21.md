# R-21：高負荷の燃料の増量と，排気の温度の制限

## 要求

タービンの入口（過給機が無い設定では，排気の合流部）の気体の温度の 1 サイクルの平均を求め，設定した上限を超える運転点では，目標の当量比を上げて上限に収めること（`docs/model/eq-fuel.md` の E-N01，E-N02）．当量比の上限も設定できること．

## 受入基準

1. 保存（系の全体で，質量，エネルギー，原子）と，式との一致（`docs/model/README.md` の決まり．式から道具が作る）．
2. `docs/model/checks-engine.md` の R-21 の行（K-104，K-105）．
