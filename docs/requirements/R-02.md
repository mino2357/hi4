# R-02：波の伝播の精度と，衝撃波

## 要求

圧力波が，正しい速さと振幅で管の中を伝わること．強い波が衝撃波になっても，数値的な振動を抑えて計算を続けられること（再構成と数値流束は `docs/model/eq-pipe.md` の E-P10，E-P11）．密度や圧力が正でない値，有限でない値になったときは，それを状態にせず，計算を止めて場所と時刻を知らせること．検証のために，比熱が一定の気体を設定できること．
