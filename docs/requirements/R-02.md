# R-02：波の伝播の精度と，衝撃波

## 要求

圧力波が，正しい速さと振幅で管の中を伝わること．強い波が衝撃波になっても，数値的な振動を出さずに計算を続けられること．密度や圧力が正でない値，有限でない値になったときは，それを状態にせず，計算を止めて場所と時刻を知らせること．

## 受入基準

判定値は実装の前の案で，実行して確かめていない．値の根拠は，仕様のテスト項目に書く．

1. **衝撃波管（Sod 1978 の条件）**：比熱一定（$\gamma = 1.4$），左右の密度の比 $8$，圧力の比 $10$，$200$ セルで，波が端に届く前の時刻の密度の $L^1$ 誤差（厳密解との差の絶対値の平均）が，高圧側の密度の $1\%$ 以下．衝撃波と接触面の位置の誤差が $2\Delta x$ 以下．
2. **排気に近い条件の衝撃波管**：高圧側 $500\ \text{kPa}$・$1200\ \text{K}$，低圧側 $100\ \text{kPa}$・$400\ \text{K}$（比熱一定）で，密度，圧力，温度が正のまま進み，密度の $L^1$ 誤差が高圧側の密度の $2\%$ 以下．
3. **振動が無い**：1 と 2 で，密度と圧力が，初期の最小と最大の範囲から，その幅の $0.1\%$ を超えてはみ出さない．
4. **滑らかな波の次数**：振幅 $1\%$ の滑らかな圧力の山（単純波）を，急峻化する前の時刻まで進めたとき，$\Delta x$ を半分にすると圧力の $L^1$ 誤差が $0.3$ 倍以下になる．
5. **伝播の速さ**：静止した気体の中の小振幅（$0.1\%$）のパルスが距離 $L$ を進む時間が，$L/a$ と相対 $0.5\%$ 以内．
6. **急峻化**：振幅 $10\%$ の圧縮波を，単純波の理論で衝撃波ができる時刻 $t_b = \dfrac{2}{(\gamma+1)\,\max(-\partial u/\partial x)_{t=0}}$ の $2$ 倍まで進めたとき，波の前面の幅（圧力の変化の $10\%$ から $90\%$ まで）が $4$ セル以下で，3 と同じ意味で振動が無い．
7. **正でない値，有限でない値**：密度か圧力が正でない値，または有限でない値になる状態を作ると，計算が止まり，管とセルの番号と時刻が記録される．止まった後は，ステップを呼んでも状態が変わらない．1〜6 の検査では一度も起きない．
