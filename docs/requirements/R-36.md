# R-36：車両（シャシーダイナモメーター）

## 要求

動力計の代わりに，車両をクランク軸につないだ運転を選べること（`docs/model/eq-vehicle.md` の E-VH01〜E-VH03 と，`docs/model/eq-rotation.md` の E-D08．負荷の切替の「車両」）．変速比，終減速比，タイヤの半径，車両の質量，駆動系の効率，転がり抵抗の係数，空気抵抗の係数と正面の面積を設定できること．車速，駆動力，走行抵抗の時間変化を記録すること．変速比は固定で，クラッチはつながったまま，タイヤはすべらず，勾配は無いとする（この割り切りを解説に書く）．加速の時間は，モデルが予測する量で，合否の判定には使わないこと．

## 受入基準

1. 保存（系の全体で，質量，エネルギー，原子）と，式との一致（`docs/model/README.md` の決まり．式から道具が作る）．
2. `docs/model/checks-extra.md` の R-36 の行（K-136，K-137）．
