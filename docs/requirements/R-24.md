# R-24：気筒別の燃料噴射の制御

## 要求

A/F センサの出力をクランク角に同期して取り，気筒ごとの空燃比のずれを推定して，気筒ごとに噴射量を補正できること（`docs/model/eq-fuel.md` の E-N04〜E-N08）．全気筒に共通の補正と，気筒ごとの補正を，それぞれ入れたり切ったりできること．気筒ごとの噴射弁のばらつき（噴射量の倍率）を設定できること．推定の方法と制御則は仕様に書くこと．補正の後に，気筒ごとの実際の当量比の差がどれだけ残るかは，モデルが予測する量として記録し，合否の判定には使わないこと．

## 受入基準

1. 保存（系の全体で，質量，エネルギー，原子）と，式との一致（`docs/model/README.md` の決まり．式から道具が作る）．
2. `docs/model/checks-engine.md` の R-24 の行（K-111〜K-113）．
