# R-16：ノックの指標と，点火時期の制限

## 要求

未燃部の温度と筒内圧から，自着火の遅れの積分（Livengood–Wu）によるノックの指標を，気筒ごと，サイクルごとに求めること（`docs/model/eq-knock.md` の E-Q01，E-Q02）．指標が燃焼の終わりより前に $1$ に達する運転点では，点火時期を遅らせること．点火時期は，MBT と，ノックの限界のうち，遅い方にすること（E-Q03）．燃料のオクタン価を設定できること．

1. 保存（系の全体で，質量，エネルギー，原子）と，式との一致（`docs/model/README.md` の決まり．式から道具が作る）．
