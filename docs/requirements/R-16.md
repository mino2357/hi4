# R-16：ノックの指標と，点火時期の制限

## 要求

未燃部の温度と筒内圧から，自着火の遅れの積分（Livengood–Wu）によるノックの指標を，気筒ごと，サイクルごとに求めること．指標が燃焼の終わりより前に $1$ に達する運転点では，点火時期を遅らせること．点火時期は，MBT と，ノックの限界のうち，遅い方にすること．燃料のオクタン価を設定できること．

## 受入基準

判定値は実装の前の案で，実行して確かめていない．値の根拠は，仕様のテスト項目に書く．

1. **未燃部の温度**：未燃部の温度が，点火の時点の筒内の状態からの等エントロピーの変化（筒内圧に対して）の値と相対 $10^{-6}$ 以内．
2. **積分**：圧力と未燃部の温度を一定にしたとき，指標が，自着火の遅れ $\tau_{ig}$ に等しい時間で $1$ に達する（相対 $0.1\%$）．$\tau_{ig}$ が仕様に書いた式の値と一致する（相対 $10^{-12}$）．
3. **ノックの限界**：ノックが起きる運転点（全負荷，過給）で，点火時期が，指標が燃焼の終わりまで $1$ に達しない範囲で最も進んだ時期に，$0.5^\circ$CA 以内で収束する．
4. **遅い方**：点火時期が，MBT の時期とノックの限界の時期のうち遅い方に一致する（$0.5^\circ$CA 以内）．ノックが起きない運転点（低負荷）では MBT．
5. **向き**：ほかの条件が同じなら，吸気の圧力 $200\ \text{kPa}$ のノックの限界の時期は，$100\ \text{kPa}$ のときより遅い．吸気の温度 $350\ \text{K}$ のときは $310\ \text{K}$ のときより遅い．オクタン価 $91$ のときは $98$ のときより遅い．
