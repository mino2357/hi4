# R-12：シリンダの気体の式（2 ゾーン，第一法則，組成，既燃ガスの割合）

## 要求

シリンダの中の気体を，0 次元の開いた系として，質量，エネルギー，組成の式で進めること（`docs/model/eq-zone.md` の E-Z01〜E-Z13）．燃焼の間は，未燃部と既燃部の 2 ゾーン（圧力は共通，温度は別）に分けること（Q-11）．燃焼の前は未燃部だけ，燃焼の後は既燃部だけとし，燃え残った未燃部は，燃焼の終わりに既燃部に混ぜること．吸気弁と排気弁は，管端の絞り（R-03）としてシリンダを容器につなぐこと．物性は `ice_2026` の REQ-29 と同じ値にすること．気筒ごと，サイクルごとに，吸気弁が閉じた時点の既燃ガスの割合（E-Z13．既燃ガスは由来を問わない：前のサイクルから残った分，排気管から吹き戻った分，吸気側へ吹き返して吸い直した分，外部 EGR の分を区別しない．未燃の空気，燃料の蒸気，液体の燃料は含まない）を求めること．

## 受入基準

1. 保存（系の全体で，質量，エネルギー，原子）と，式との一致（`docs/model/README.md` の決まり．式から道具が作る）．
2. `docs/model/checks-cylinder.md` の R-12 の行（K-65〜K-69）．
