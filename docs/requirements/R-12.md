# R-12：シリンダの気体の式（2 ゾーン，第一法則，組成，残留ガス）

## 要求

シリンダの中の気体を，0 次元の開いた系として，質量，エネルギー，組成の式で進めること．燃焼の間は，未燃部と既燃部の 2 ゾーン（圧力は共通，温度は別）に分けること（Q-11）．燃焼の前は未燃部だけ，燃焼の後は既燃部だけとし，燃え残った未燃部は，燃焼の終わりに既燃部に混ぜること．吸気弁と排気弁は，管端の絞り（R-03）としてシリンダを容器につなぐこと．物性は `ice_2026` の REQ-29 と同じ値にすること．気筒ごと，サイクルごとの残留ガスの割合を求めること．

## 受入基準

判定値は実装の前の案で，実行して確かめていない．値の根拠は，仕様のテスト項目に書く．

1. **断熱の圧縮**：弁を閉じ，壁への熱と燃焼を無くした圧縮で，比熱一定の気体なら $pV^{\gamma}$ が一定（相対 $10^{-6}$）．温度で比熱が変わる気体では，内部エネルギーの増分が $-\int p\,dV$ と相対 $10^{-6}$ 以内で合う．
2. **2 ゾーンの和**：燃焼の間，どの時刻でも $V_u + V_b = V$，$m_u + m_b = m$（相対 $10^{-12}$）で，2 つのゾーンの圧力が同じ．2 つのゾーンの内部エネルギーの和の増分が，$-\int p\,dV$，壁への熱の和，弁を通る全 enthalpy の積算の和に，相対 $10^{-9}$ 以内で合う．
3. **未燃部の温度**：壁への熱を無くしたとき，燃焼の間の未燃部の温度が，燃焼の始まりの状態からの等エントロピーの変化（筒内圧に対して）の値と相対 $10^{-6}$ 以内．
4. **混ぜる**：燃焼の終わりに未燃部を既燃部に混ぜる前後で，筒内の全質量，全内部エネルギー，各成分の質量が変わらない（相対 $10^{-12}$）．
5. **質量と成分の保存**：シリンダと管を合わせた閉じた系（大気への端を閉じる）で，全質量と，空気に由来する質量，燃料に由来する質量の変化が，相対 $10^{-12}$ 以下．
6. **サイクルの第一法則**：周期定常の 1 サイクルで，筒内の第一法則の残差（内部エネルギーの増分，仕事，壁への熱，弁を通る全 enthalpy，燃料の持ち込む enthalpy の和）が，供給した燃料の発熱量の $10^{-4}$ 以下．
7. **残留ガスの割合**：吸気弁が閉じた時点の，筒内の既燃ガスの質量を筒内の全質量で割った値が，気筒ごと，サイクルごとに記録される．排気弁と吸気弁を通った既燃ガスの積算から求めた値と相対 $10^{-9}$ 以内で合う．
8. **有限**：弁の時期を，作用角が $1^\circ$ 以上 $719^\circ$ 以下の範囲でどう組み合わせても，状態が有限のままである（機関が止まる，失火するのはよい）．
