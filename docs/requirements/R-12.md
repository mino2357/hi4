# R-12：シリンダの気体の式（第一法則，組成，残留ガス）

## 要求

シリンダの中の気体を，0 次元・単一ゾーンの開いた系として，質量，エネルギー，組成の式で進めること．吸気弁と排気弁は，管端の絞り（R-03）としてシリンダを容器につなぐこと．筒内の既燃ガスは化学平衡の組成とし，物性は `ice_2026` の REQ-29 と同じ値にすること．気筒ごと，サイクルごとの残留ガスの割合を求めること．

## 受入基準

判定値は実装の前の案で，実行して確かめていない．値の根拠は，仕様のテスト項目に書く．

1. **断熱の圧縮**：弁を閉じ，壁への熱と燃焼を無くした圧縮で，比熱一定の気体なら $pV^{\gamma}$ が一定（相対 $10^{-6}$）．温度で比熱が変わる気体では，内部エネルギーの増分が $-\int p\,dV$ と相対 $10^{-6}$ 以内で合う．
2. **質量と成分の保存**：シリンダと管を合わせた閉じた系（大気への端を閉じる）で，全質量と各成分の質量の変化が，燃焼が無いとき相対 $10^{-12}$ 以下．
3. **サイクルの第一法則**：周期定常の 1 サイクルで，筒内の第一法則の残差（内部エネルギーの増分，仕事，壁への熱，弁を通る全 enthalpy，燃料の持ち込む enthalpy の和）が，供給した燃料の発熱量の $10^{-4}$ 以下．
4. **化学平衡の値**：燃料と空気（$298.15\ \text{K}$，$101.325\ \text{kPa}$）の定圧の断熱火炎温度が，$\phi = 1.0$ で $2313.7\ \text{K}$，$\phi = 1.1$ で $2325.2\ \text{K}$（$\pm 2\ \text{K}$．`ice_2026` の REQ-29 の受入基準 3 と同じ値）．
5. **残留ガスの割合**：吸気弁が閉じた時点の，筒内の既燃ガスの質量（空気に由来する分と燃料に由来する分の和）を筒内の全質量で割った値が，気筒ごと，サイクルごとに記録される．排気弁と吸気弁を通った既燃ガスの積算から求めた値と相対 $10^{-9}$ 以内で合う．
6. **有限**：弁の時期を，作用角が $1^\circ$ 以上 $719^\circ$ 以下の範囲でどう組み合わせても，状態が有限のままである（機関が止まる，失火するのはよい）．
