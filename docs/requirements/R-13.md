# R-13：燃焼，既燃ガスの化学（平衡と凍結），筒内の壁面熱伝達

## 要求

燃焼を，未燃部の空気と燃料の蒸気が既燃部へ移る質量の流れとして表し，その進み方を Wiebe 関数で与えること（機関であること（G-01）から要る）．発熱は，外から加える項ではなく，内部エネルギー（生成 enthalpy を含む絶対値）の差として現れること．既燃部の組成は，高温では化学平衡（既燃部の温度，圧力，当量比から）とし，膨張で温度が下がった後は凍結すること（条件は Q-12）．排気弁を出る気体は，凍結した組成（CO と H₂ を含む）を持つこと．燃焼の期間は，筒内の状態（密度，残留ガスの割合，回転数）によって変わること．筒内の壁への熱を Woschni の式で求め，2 つのゾーンに配ること．

## 受入基準

判定値は実装の前の案で，実行して確かめていない．値の根拠は，仕様のテスト項目に書く．

1. **Wiebe 関数**：燃えた割合が $x_b(\theta) = 1 - \exp\!\left[-a_W \left(\dfrac{\theta - \theta_s}{\Delta\theta_b}\right)^{m_W + 1}\right]$ に一致する（相対 $10^{-12}$）．燃焼の速さは，クランク軸が逆に回る段でも $0$ 以上．
2. **燃える量**：1 サイクルに既燃部へ移る燃料の質量が，筒内の燃料の蒸気の質量と，筒内の空気の質量を量論空燃比で割った値の，小さい方に燃焼効率を掛けた値と相対 $10^{-9}$ 以内．
3. **原子の保存**：燃焼，平衡，凍結のどの段階でも，C，H，O，N の原子の数が保存する（相対 $10^{-9}$）．
4. **化学平衡の値**：燃料と空気（$298.15\ \text{K}$，$101.325\ \text{kPa}$）の定圧の断熱火炎温度が，$\phi = 1.0$ で $2313.7\ \text{K}$，$\phi = 1.1$ で $2325.2\ \text{K}$（$\pm 2\ \text{K}$．`ice_2026` の REQ-29 の受入基準 3 と同じ値）．
5. **定容・断熱の燃焼**：定容・断熱で全部が燃え，1 つに混ざった後の温度と圧力が，`ice_2026` の REQ-29 の受入基準 4 と同じ条件で同じ値（$\phi = 1.0$ で $2952\ \text{K}$，$9.565\ \text{MPa}$．$\phi = 1.1$ で $2983\ \text{K}$，$9.817\ \text{MPa}$．$\pm 5\ \text{K}$，$\pm 0.3\%$）．燃焼の途中では，既燃部の温度が未燃部の温度より高い．
6. **凍結**：凍結の後は，既燃ガスの各種のモル分率が変わらない（相対 $10^{-12}$）．全負荷・$3000\ \text{rpm}$・$\phi = 1.0$ で，排気弁を出る気体の CO のモル分率が，排気弁が開く時点の温度と圧力での平衡の値より大きい．
7. **燃焼の期間**：ほかの条件が同じなら，残留ガスの割合が大きいほど燃焼の期間（クランク角）が長く，筒内の密度が高いほど短い（残留ガスの割合 $0.05$ と $0.20$，吸気の圧力 $100\ \text{kPa}$ と $200\ \text{kPa}$ で比べる）．
8. **壁への熱**：壁への熱伝達率が，仕様に書いた Woschni の式の値と一致する（相対 $10^{-12}$）．2 つのゾーンへ配った熱の和が，全体の値に一致する（相対 $10^{-12}$）．
