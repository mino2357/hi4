# R-13：燃焼，既燃ガスの化学（拘束した平衡と CO の反応速度），筒内の壁面熱伝達

## 要求

燃焼を，未燃部の空気と燃料の蒸気が既燃部へ移る質量の流れとして表し，その進み方を Wiebe 関数で与えること（機関であること（G-01）から要る）．発熱は，外から加える項ではなく，内部エネルギー（生成 enthalpy を含む絶対値）の差として現れること．既燃部の組成は，CO と NO を反応速度の式で解き（NO は R-17），残りの種を，その 2 つの量を拘束した化学平衡（温度，圧力，元素の量から）で決めること．凍結のしきい値は置かず，温度が下がると反応が遅くなって組成が変わらなくなることが，式から現れること．CO と NO は，元素の収支とエネルギーに厳密に入れること．同じ式を，管と容積の中でも解くこと（R-06）．燃焼の期間は，筒内の状態（密度，吸気弁が閉じた時点の既燃ガスの割合 $x_{b,IVC}$（定義は R-12），回転数）によって変わること．筒内の壁への熱を Woschni の式で求め，2 つのゾーンに配ること．

## 受入基準

判定値は実装の前の案で，実行して確かめていない．値の根拠は，仕様のテスト項目に書く．

1. **Wiebe 関数**：燃えた割合が $x_b(\theta) = 1 - \exp\!\left[-a_W \left(\dfrac{\theta - \theta_s}{\Delta\theta_b}\right)^{m_W + 1}\right]$ に一致する（相対 $10^{-12}$）．燃焼の速さは，クランク軸が逆に回る段でも $0$ 以上．
2. **燃える量**：1 サイクルに既燃部へ移る燃料の質量が，筒内の燃料の蒸気の質量と，筒内の空気の質量を量論空燃比で割った値の，小さい方に燃焼効率を掛けた値と相対 $10^{-9}$ 以内．
3. **原子の保存**：燃焼と反応のどの段階でも，C，H，O，N の原子の数が保存する（相対 $10^{-9}$）．
4. **化学平衡の値**：燃料と空気（$298.15\ \text{K}$，$101.325\ \text{kPa}$）の定圧の断熱火炎温度が，$\phi = 1.0$ で $2313.7\ \text{K}$，$\phi = 1.1$ で $2325.2\ \text{K}$（$\pm 2\ \text{K}$．`ice_2026` の REQ-29 の受入基準 3 と同じ値）．
5. **定容・断熱の燃焼**：定容・断熱で全部が燃え，1 つに混ざった後の温度と圧力が，`ice_2026` の REQ-29 の受入基準 4 と同じ条件で同じ値（$\phi = 1.0$ で $2952\ \text{K}$，$9.565\ \text{MPa}$．$\phi = 1.1$ で $2983\ \text{K}$，$9.817\ \text{MPa}$．$\pm 5\ \text{K}$，$\pm 0.3\%$）．燃焼の途中では，既燃部の温度が未燃部の温度より高い．
6. **CO の式**：反応による CO の濃度の変化の速さが $(R_a + R_c)\left(1 - \dfrac{[\mathrm{CO}]}{[\mathrm{CO}]_e}\right)$（記号は D-24）と一致する（相対 $10^{-12}$）．温度と圧力を一定にしたとき，CO の濃度の時間変化が $\gamma_{\mathrm{CO}}(t) = 1 + (\gamma_{\mathrm{CO}}(0) - 1)\exp(-t/\tau_{\mathrm{CO}})$ と相対 $0.1\%$ 以内．時間の刻みを $10$ 倍にしても，値が有限で，振動せず，同じ値に収束する．
7. **拘束した平衡**：CO と NO の量を与えて求めた残りの種の組成が，元素の保存を満たし（相対 $10^{-9}$），$\mathrm{H_2} + \tfrac12\mathrm{O_2} \rightleftharpoons \mathrm{H_2O}$ の平衡定数の関係を満たす（相対 $10^{-6}$）．CO と NO の量を，拘束しない平衡の値にすると，拘束しない平衡の組成に一致する（相対 $10^{-6}$）．
8. **壁への熱**：壁への熱伝達率が，仕様に書いた Woschni の式の値と一致する（相対 $10^{-12}$）．2 つのゾーンへ配った熱の和が，全体の値に一致する（相対 $10^{-12}$）．
