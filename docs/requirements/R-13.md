# R-13：燃焼，既燃ガスの化学（拘束した平衡と CO の反応速度），筒内の壁面熱伝達

## 要求

燃焼を，未燃部の空気と燃料の蒸気が既燃部へ移る質量の流れとして表し，その進み方を Wiebe 関数で与えること（`docs/model/eq-combustion.md` の E-X01〜E-X06．機関であること（G-01）から要る）．発熱は，外から加える項ではなく，内部エネルギー（生成 enthalpy を含む絶対値）の差として現れること．既燃部の組成は，CO と NO を反応速度の式で解き（NO は R-17），残りの種を，その 2 つの量を拘束した化学平衡で決めること（`docs/model/eq-chem.md` の E-R01〜E-R03，E-R05）．凍結のしきい値は置かないこと．CO と NO は，元素の収支とエネルギーに厳密に入れること．同じ式を，管と容積の中でも解くこと（R-06）．筒内の壁への熱を Woschni の式で求め，2 つのゾーンに配ること（`docs/model/eq-cylwall.md` の E-Y01〜E-Y04）．

## 受入基準

1. 保存（系の全体で，質量，エネルギー，原子）と，式との一致（`docs/model/README.md` の決まり．式から道具が作る）．
2. `docs/model/checks-cylinder.md` の R-13 の行（K-70〜K-75）．
