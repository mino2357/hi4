# R-13：燃焼と，筒内の壁面熱伝達

## 要求

燃焼を，未燃の空気と燃料の蒸気が既燃ガスに変わる組成の変化として表し，その進み方を Wiebe 関数で与えること（機関であること（G-01）から要る）．発熱は，外から加える項ではなく，内部エネルギー（生成 enthalpy を含む絶対値）の差として現れること．燃焼の期間は，筒内の状態（密度，残留ガスの割合，回転数）によって変わること．筒内の壁への熱を，Woschni の式で求めること．

## 受入基準

判定値は実装の前の案で，実行して確かめていない．値の根拠は，仕様のテスト項目に書く．

1. **Wiebe 関数**：燃えた割合が $x_b(\theta) = 1 - \exp\!\left[-a_W \left(\dfrac{\theta - \theta_s}{\Delta\theta_b}\right)^{m_W + 1}\right]$ に一致する（相対 $10^{-12}$）．燃焼の速さは，クランク軸が逆に回る段でも $0$ 以上．
2. **燃える量**：1 サイクルに既燃ガスへ移る燃料の質量が，筒内の燃料の蒸気の質量と，筒内の空気の質量を量論空燃比で割った値の，小さい方に燃焼効率を掛けた値と相対 $10^{-9}$ 以内．
3. **原子の保存**：燃焼の前後で，空気に由来する質量の合計と，燃料に由来する質量の合計が，それぞれ保存する（相対 $10^{-12}$）．
4. **定容・断熱の燃焼**：定容・断熱の燃焼の終わりの温度と圧力が，`ice_2026` の REQ-29 の受入基準 4 と同じ条件で同じ値（$\phi = 1.0$ で $2952\ \text{K}$，$9.565\ \text{MPa}$．$\phi = 1.1$ で $2983\ \text{K}$，$9.817\ \text{MPa}$．$\pm 5\ \text{K}$，$\pm 0.3\%$）．
5. **燃焼の期間**：ほかの条件が同じなら，残留ガスの割合が大きいほど燃焼の期間（クランク角）が長く，筒内の密度が高いほど短い（残留ガスの割合 $0.05$ と $0.20$，吸気の圧力 $100\ \text{kPa}$ と $200\ \text{kPa}$ で比べる）．
6. **壁への熱**：壁への熱伝達率が，仕様に書いた Woschni の式の値と一致する（相対 $10^{-12}$）．筒内の気体の温度が壁温に等しいとき，熱は $0$．
