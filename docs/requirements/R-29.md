# R-29：twin-scroll

## 要求

タービンの入口を 2 つ（既定は気筒 1・4 の排気と，気筒 2・3 の排気）に分けた形を選べること．2 つの入口は，それぞれタービンの流路の半分を受け持ち，同じ翼車を駆動すること．single-scroll と切り替えて比べられること．2 つの入口の状態が違うとき（部分的な流入）の特性は近似であることを，解説に書くこと．

## 受入基準

判定値は実装の前の案で，実行して確かめていない．値の根拠は，仕様のテスト項目に書く．

1. **同じ状態の極限**：2 つの入口の状態が同じとき，流量の合計と仕事率が，single-scroll の式（R-26 の受入基準 1）の値と相対 $10^{-9}$ 以内で一致する．
2. **片方だけ**：片方の入口の膨張比が $1$ のとき，その入口の流量が $0$ で，もう片方の流量と仕事率が，仕様に書いた式の値と一致する（相対 $10^{-12}$）．
3. **分離**：2 つの入口の容積の間に，タービンの外を通る流れが無い（2 つの容積の間の面を通る質量が $0$）．
4. **エネルギー**：2 つの入口から出る全 enthalpy の流れの和から仕事率を引いた値が，出口の容積に入る全 enthalpy の流れに一致する（相対 $10^{-12}$）．
