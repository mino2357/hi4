# R-29：twin-scroll

## 要求

タービンの入口を 2 つ（既定は気筒 1・4 の排気と，気筒 2・3 の排気）に分けた形を選べること．2 つのスクロールは，それぞれの出口の絞りを通って，翼車の直前の共通の空間に入り，そこから翼車を通ること（式は D-25）．スクロールの間の干渉（片方から他方への逆流）は，この式から現れること（係数を別に置かない）．single-scroll と切り替えて比べられること．2 つのスクロールの状態が違うときの仕事率の式は仮定であることを，解説に書くこと．干渉の大きさ（逆流した質量）は，予測する量として記録すること．当面，合否は，保存されるべき量が保存することで判定する（利用者の決定．2026-11-28）．式との一致と極限の基準は，仕様で式が決まった後に加えるかを確かめる．

## 受入基準

判定値は実装の前の案で，実行して確かめていない．値の根拠は，仕様のテスト項目に書く．

1. **質量**：どの時刻でも $\lvert \dot m_1 + \dot m_2 - \dot m_r\rvert \le 10^{-12}\,\dot m_{ref}$（$\dot m_{ref}$ は 3 つの流量の絶対値の最大）．2 つのスクロール，出口の容積を合わせた閉じた系で，全質量が保存する（相対 $10^{-12}$）．
2. **エネルギー**：2 つのスクロールから出た全 enthalpy の積算が，出口の容積に入った全 enthalpy の積算，逆流でスクロールへ戻った全 enthalpy の積算，仕事 $\int P_t\,dt$ の和に，相対 $10^{-12}$ 以内で合う．
3. **成分**：空気に由来する質量，燃料に由来する質量，CO，NO のそれぞれについて，1 と同じ収支が成り立つ（相対 $10^{-12}$）．
