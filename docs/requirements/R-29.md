# R-29：twin-scroll

## 要求

タービンの入口を 2 つ（既定は気筒 1・4 の排気と，気筒 2・3 の排気）に分けた形を選べること．`docs/model/eq-turbine.md` の式（E-W01〜E-W09）で計算すること．スクロールの間の干渉（片方から他方への逆流）は，この式から現れること（係数を別に置かない）．single-scroll と切り替えて比べられること．仕事率の式（E-W08）は仮定であることを，解説に書くこと．干渉の大きさ（逆流した質量）は，予測する量として記録すること．当面，合否は，保存されるべき量（質量，エネルギー，成分）が保存することで判定する（利用者の決定．2026-11-28）．
